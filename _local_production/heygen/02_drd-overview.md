## Cel filmu

- Uwiarygodnić metodę: **Demand / Resources / Dependencies**.
- Powiązać metodę z tym co widać w aplikacji: assessment → inicjatywy → roadmap.

## Obsada / aktorzy

- **Teresa (HeyGen avatar)**: intro + 3 punkty metodologii + summary/CTA.
- **Screen recording**: krótki pokaz assessmentu 10-wymiarowego + inicjatywy + roadmap.
- **Opcjonalny B-roll**: 1–2 przebitki (fabryka / tablica wskaźników) jako tło pod definicje DRD (maks 2s).

## Ujęcia z aplikacji (screen checklist)

1. Widok assessmentu 10-dimension (lista wymiarów).
2. Wynik/score + porównanie (jeśli jest) albo drill-down w wymiar.
3. Widok inicjatyw wygenerowanych z gapów.
4. Widok roadmap (oś czasu / plan).

### Scene 5 — Summary + CTA (2:30–3:00)
- **Teresa**: “DRD to fokus na to co ma znaczenie” + CTA.
