# Sources & Citation Style Guide (Strategic Tools Catalog)

## Principles

- Prefer **primary sources**: original authors, reputable institutions (Harvard/ISC, BCG, MIT, OECD, well-known publishers).
- Use **at least 3** sources per tool; prefer 5–10 when available.
- Avoid low-quality blogs. If used for “how-to”, pair with authoritative sources.
- When a framework has multiple competing interpretations, document the **canonical** one and list variants.

## What to cite

- Definitions and the canonical model structure
- Step-by-step method variations (e.g., JTBD interview format)
- Visualization conventions (e.g., GE/McKinsey axes)
- Known limitations / critiques

## How to cite

- Use a bulleted list in the **References** section.
- Use descriptive link text.
- Do not paste bare URLs in prose; use Markdown links.

Example:

- [Harvard Business School — Institute for Strategy and Competitiveness: The Value Chain](https://www.isc.hbs.edu/strategy/Pages/value-chain.aspx)

## Minimum bar for “authoritative”

At least one of:

- Harvard Business School / Institute for Strategy and Competitiveness
- BCG publications (Classics Revisited, etc.)
- McKinsey insights (Enduring Ideas, etc.)
- Peer-reviewed journals / books by original authors
- Recognized industry institutions (OECD, World Economic Forum) when relevant
