# VRIO (Resource-Based View)

## Metadata

- **Tool name**: VRIO
- **Slug**: `vrio`
- **Category**: Strategy
- **Level**: Core
- **Typical duration**: 90–180 minutes (workshop)
- **Best for**: Internal strategy: identifying sustainable advantages and capability gaps
- **Primary outputs**: VRIO table, advantage classification, capability build initiatives
- **Created**: 2026-01-31
- **Last updated**: 2026-01-31

---

## Purpose

VRIO evaluates resources/capabilities by four questions:\n- Value\n- Rarity\n- Imitability\n- Organization\nto determine whether they provide sustained competitive advantage.

---

## Method

1. List key resources/capabilities.\n2) Score each on V/R/I/O.\n3) Classify implication (disadvantage/parity/temporary/sustained).\n4) Decide: protect, invest, partner, or exit.\n5) Convert gaps into initiatives.

---

## UI / Graphic spec

- VRIO table with guided questions\n- “Advantage classification” badges\n- Initiative generator for capability gaps\n

---

## Worked example

Capability: “real-time production visibility.” Valuable, rare in segment, hard to imitate if tied to data + process, but requires org readiness. Initiative: data governance + change management + platform rollout.
