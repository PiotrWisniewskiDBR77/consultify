## 1. Purpose

The GE–McKinsey matrix helps a corporation decide **where to invest cash** across business units by rating each unit on:

- **Industry attractiveness** (external)
- **Competitive strength** (internal)
  and then choosing an investment posture (invest/select/harvest).

---

## 2. Method (step-by-step)

1. Define portfolio units (BU/product line/segment).\n2) Choose factors for the two axes.\n3) Weight factors (sum to 1 per axis).\n4) Score each unit for each factor.\n5) Compute weighted axis scores (0–100).\n6) Place units in 3×3 grid.\n7) Define posture per cell (Invest / Select / Harvest).\n8) Translate posture into initiatives (grow, defend, divest, improve).

---

## 3. Outputs & DoD

- 9-box map of units\n- Scorecards (factors + weights)\n- Portfolio posture decisions\n- Initiatives per unit

DoD:

- [ ] Units defined\n- [ ] Factors and weights agreed\n- [ ] All units scored\n- [ ] Posture decisions documented\n- [ ] ≥3 initiatives per “Invest/Grow” unit

---

## 4. UI / Graphic spec

- 3×3 matrix with draggable dots\n- Side panel: factor weights and scoring\n- Click unit dot → unit profile + recommended posture + initiative themes\n- Export: PDF portfolio map + scorecards

---

## 5. Worked example

Portfolio with 5 product lines.\n- “A” in high attractiveness / high strength → invest and grow.\n- “B” high attractiveness / low strength → selective investment, capability build.\n- “C” low attractiveness / low strength → harvest/divest.\nInitiatives: cost position improvement, channel expansion, divest plan.
