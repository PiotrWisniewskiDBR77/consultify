# Image Prompts

## Hero

Objective: show one connected operating sequence from simulation to execution to automation.

Prompt:
Waist-high editorial photograph: steel linear track on a tooling bench with **three** sequential stations—clear acrylic scenario maze block, brushed run plate with footprint marks, small integrator turnkey latch—linked by a single metal carrier puck mid-track; background softly shows real plant. Express “simulate → run → automate” as **motion rig**, not screens or callouts.

Negative prompts: step labels 1-2-3 with text, AR arrows, dashboard strip, cyber overlay, glowing HUD

Constraints: no readable text; tactile sequence only; Mode 2 physical lane

Aspect ratio: 16:9
## Analytical

Objective: visualize the DBR77 sequence as one operating logic.

Prompt:
Waist-high editorial photograph of one machined steel operating rig on a workbench with three real linked stations, one traveling brass carrier, one verification gate, and one reset latch showing a continuous simulate-run-automate sequence through physical hardware only; no toy diorama, no software panels, no floating overlays, no printed instructions

Negative prompts: generic stock meeting scene, flashy sci-fi, neon overlays, cartoon metaphor, fake futuristic interface

Constraints: no text, no labels, no numbers, no clutter, no generic charts without industrial context, no decorative UI overload, every module and signal must stay abstract and non-legible, real bench materials only

Aspect ratio: 16:9
## Social

Objective: create a strong system-story visual around the phrase "simulate, run, automate".

Prompt:
Square macro editorial of three real machined stations on a worn steel plate with one brass puck parked halfway through the sequence, shallow depth, sharp metal texture, tactile workshop realism, no poster symbolism, no toy icons, no neon

Negative prompts: numbered captions, arrow stickers with text, cinematic lens flare cyber, icon trio, app-icon look

Constraints: no text; strong center focal for 1:1 crop; Mode 2 social

Aspect ratio: 1:1

Optional variant: 4:5
