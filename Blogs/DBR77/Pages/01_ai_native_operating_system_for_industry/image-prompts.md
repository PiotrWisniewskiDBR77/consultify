# Image Prompts

## Hero

Objective: show DBR77 as one intelligent industrial operating system rather than a disconnected set of tools.

Prompt:
Editorial industrial ecosystem scene showing a modern manufacturing environment connected by one clear operating logic across machine data, simulation, execution control, automation sourcing, and governance, expressed through embedded industrial cues, abstract control surfaces, and physical operating continuity rather than hologram clutter, overlay graphics, or readable dashboards, premium B2B strategic style, realistic factory context, calm intelligent mood, wide landscape composition, no sci-fi hologram clutter, no generic dashboard wall

Negative prompts: generic stock meeting scene, flashy sci-fi, neon overlays, cartoon metaphor, fake futuristic interface

Constraints: no text, no logos, no brand names, realistic industrial or executive context, no staged stock-photo poses, no sci-fi UI, no floating overlay graphics, all screens and boards must stay abstract and non-legible

Aspect ratio: 16:9
## Analytical

Objective: visualize the five-layer DBR77 operating logic.

Prompt:
Overhead editorial photograph: **five** distinct horizontal trays (oak, slate, brushed aluminum, cork, steel) stacked with slight offset like a physical layer cake—each holds different industrial tokens (gears, felt pads, clear scenario cubes, relay blocks, stamp dies) linked by **cord runs** through eyelets. Reads as one operating stack **without** layer titles, software stack diagrams, or callout text. Soft top light.

Negative prompts: layered software diagram, cloud icons with words, stack labels L1–L5, floating panels, sci-fi stack

Constraints: no legible text; five trays visually distinct; Mode 2 physical explanatory rig

Aspect ratio: 16:9
## Social

Objective: create a strong category visual around the phrase "AI-native operating system for industry".

Prompt:
Premium editorial industrial image with one coherent decision layer spanning the factory, using one center-safe thesis moment instead of headline space or poster treatment, realistic manufacturing setting, dark graphite palette with one accent color, strategic and credible mood, no neon sci-fi, no robot hero cliché

Negative prompts: headline baked into image, meme aesthetic, smiling stock characters, cheesy corporate poster, sci-fi neon

Constraints: no text in the generated image, keep the key subject inside the center-safe crop for social or newsletter reuse, no baked headline area, no poster typography, no readable labels

Aspect ratio: 1:1

Optional variant: 4:5
