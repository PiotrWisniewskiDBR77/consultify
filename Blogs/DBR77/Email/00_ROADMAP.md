# DBR77 Email Layer Roadmap

Status: can start now from DBR77 umbrella pages, blog series, funnel logic, and publication matrix.

## Purpose

This layer turns DBR77 category and page assets into reusable outbound and nurture email angles.

Use it for:

- first contact
- nurture for non-buyers
- role-based progression toward a strategic conversation

## Source Priority

1. `Blogs/_OPERATIONS/core/DBR77_FUNNEL_ASSET_MAP.md`
2. `Blogs/_OPERATIONS/core/DBR77_PUBLICATION_MATRIX.md`
3. `Blogs/DBR77/Pages/*`
4. `Blogs/DBR77/Blog/*`
5. `https://dbr77.com/`

## Packaging Rule

Each email asset should include:

- persona
- suggested sender
- stage
- subject options
- core angle
- full email draft
- CTA
- source asset bridges

## Initial Backlog

1. Owner / Chairman: Where does guesswork still sit in your factory?
2. Plant Manager / Operations: Busy is not the same as controlled
3. CFO: The hidden cost most factories do not measure
4. CTO: What a decision system in manufacturing actually means
5. Purchasing Director: Which layer of automation friction is costing you most?

## Rules

- keep emails short, clear, and role-specific
- sound like an experienced human, not syndicated content
- start from the bottleneck, not from the product
- use one CTA only
- bridge to one page or article when possible

## Default CTA Logic

- first contact: read this / explore this
- nurture: stay close / see how others approach it
- decision support: schedule a strategic conversation
