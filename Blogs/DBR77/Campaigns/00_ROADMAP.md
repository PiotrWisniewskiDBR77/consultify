# DBR77 Campaign Layer Roadmap

Status: can start now from completed DBR77 blog, pages, email, social, and persona layers.

## Purpose

This layer turns DBR77 assets into executable campaign playbooks.

Use it for:

- persona-led outbound
- nurture sequences
- coordinated page + email + social distribution
- repeating campaign execution without rebuilding logic each time

## Source Priority

1. `Blogs/DBR77/Personas/*`
2. `Blogs/DBR77/Email/*`
3. `Blogs/DBR77/Social/*`
4. `Blogs/DBR77/Pages/*`
5. `Blogs/DBR77/Blog/*`
6. `Blogs/_OPERATIONS/core/DBR77_PUBLICATION_MATRIX.md`
7. `Blogs/_OPERATIONS/core/DBR77_FUNNEL_ASSET_MAP.md`

## Packaging Rule

Each campaign playbook should include:

- objective
- persona
- suggested sender / face
- stage
- primary CTA
- core message
- asset stack
- execution sequence
- outreach notes
- success signals

## Initial Backlog

1. CEO / Chairman: Better Board Control campaign
2. CFO: Safer CAPEX and Clearer ROI campaign
3. CTO: Decision Architecture campaign
4. Plant Manager: Less Firefighting campaign

## Rules

- one campaign = one persona + one clear bottleneck
- use one strongest page as the anchor asset
- pair one email with one social post minimum
- route to one CTA only
- keep sequences short enough to execute manually
