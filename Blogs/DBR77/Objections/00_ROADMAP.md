# DBR77 Objections Battlecards Roadmap

Status: can start now from completed DBR77 pages, campaigns, company assets, and sales scripts.

## Purpose

This layer turns common buying objections into direct-response sales battlecards.

Use it for:

- objection handling in calls
- email follow-up after resistance
- sales enablement and training
- preparing leadership, technical, and commercial conversations

## Packaging Rule

Each battlecard should include:

- objection
- typical speaker
- why it appears
- bad response to avoid
- better response logic
- short answer
- expanded answer
- proof bridges
- primary CTA

## Initial Backlog

1. ROI and budget
2. Security and governance
3. Integration and tool sprawl
4. Timing and change capacity
5. We already have systems / status quo

## Rules

- never answer objections with hype
- reduce perceived risk before adding pressure
- speak to the logic behind the objection, not only the wording
- route each objection to one strongest next step
