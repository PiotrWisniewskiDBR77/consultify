# DBR77 Persona Pages Roadmap

Status: can start now from DBR77 umbrella pages, blog series, email angles, and publication matrix.

## Purpose

This layer turns DBR77 umbrella messaging into role-specific cross-product landing pages.

Use it for pages that should:

- speak directly to one decision-maker role
- translate the ecosystem into role-specific value
- connect category clarity with buying relevance
- support persona-specific outbound and nurture

Each persona page package should include:

- `page_EN.md`

## Rules

- start from the persona's real buying logic
- keep the page cross-product, not product-dump-driven
- route naturally to the right product entry points
- use executive language for CEO / CFO and more operational language for CTO / Plant Manager
