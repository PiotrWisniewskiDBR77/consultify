## Opening logic

Start from overload, reaction speed, and busy-versus-control tension.
Keep the language operational and practical.

Subject option:
Busy is not the same as controlled

Draft:

Usually that is not only a staffing issue.
It is a control issue caused by truth arriving late, ownership staying unclear, and too much response happening after the problem has already spread.

We have been using one short page to explain how stronger governed execution reduces firefighting without adding another reporting layer.

If useful, I can send it over.

One pattern we keep seeing:
plants are active, but not truly in control.
