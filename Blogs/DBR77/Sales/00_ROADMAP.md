# DBR77 Sales Scripts Roadmap

Status: can start now from completed DBR77 pages, email assets, social assets, persona pages, campaigns, and company assets.

## Purpose

This layer turns DBR77 content into direct sales-use scripts.

Use it for:

- first-contact outreach
- follow-up messaging
- LinkedIn DMs
- call openers
- role-based progression toward a strategic conversation

## Source Priority

1. `Blogs/DBR77/Email/*`
2. `Blogs/DBR77/Personas/*`
3. `Blogs/DBR77/Pages/*`
4. `Blogs/DBR77/Campaigns/*`
5. `Blogs/_OPERATIONS/core/DBR77_PUBLICATION_MATRIX.md`
6. `Blogs/_OPERATIONS/core/DBR77_FUNNEL_ASSET_MAP.md`

## Packaging Rule

Each script should include:

- persona
- suggested sender
- stage
- goal
- opening logic
- email version
- LinkedIn DM version
- follow-up version
- call opener
- primary CTA
- asset bridges

## Initial Backlog

1. Owner / Chairman
2. Plant Manager / Operations
3. CFO
4. CTO
5. Purchasing Director

## Rules

- keep every script human, short, and specific
- open from the bottleneck, not from the product name
- use one CTA only
- always route to one strongest destination asset
- make follow-up lighter, not longer
