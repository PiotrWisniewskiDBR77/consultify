# DBR77 Tag Taxonomy (CMS + Knowledge Base)

## Purpose

This file defines a consistent tag system for the DBR77 market influence system.

Use it for:

- LP knowledge base record tagging
- CMS filtering and internal curation
- publication routing and asset selection
- reporting (what we published, to whom, and why)

## Tag Types (do not mix)

### 1) Product tag (exactly 1)

One of:

- `Consultify`
- `IoT`
- `IRIS`
- `DT`
- `Marketplace`
- `Vector`

### 2) Persona tag (exactly 1 primary, optional 1 secondary)

Use the same names as the article package headers:

- `Owner / President`
- `Chairman / Managing Director`
- `CFO`
- `CTO`
- `Plant Manager`
- `Maintenance Manager`
- `Purchasing Director`
- `Supplier / Integrator`

### 3) Funnel stage tag (exactly 1)

One of:

- `Awareness`
- `Demo/Trial/Pilot Entry`
- `Decision`
- `Adoption`
- `Nurture`

### 4) Knowledge layer tag (exactly 1)

One of:

- `Layer 1: Field Reality`
- `Layer 2: Problem Deep Dives`
- `Layer 3: Solution Logic`
- `Layer 4: Decision Support`
- `Layer 5: Execution And Transformation`

### 5) LP section tag (exactly 1)

One of the public section labels from the LP model:

- `Downtime And OEE`
- `Layout And Flow`
- `CAPEX And Investment`
- `Governance And ROI`
- `Automation And Sourcing`
- `AI And Decision Making`
- `Execution And Rollout`

### 6) Theme tags (0–5)

Themes are optional but useful for filtering within sections. Use short nouns:

- `ROI`
- `CAPEX`
- `Security`
- `Governance`
- `Approval`
- `Vendor Comparison`
- `OEE`
- `Downtime`
- `Data Quality`
- `Architecture`
- `Integration`

## Source Of Truth For Tagging

Use generated catalog files:

- `Blogs/_DATA/catalogs/DBR77_CONTENT_CATALOG.csv`
- `Blogs/_DATA/catalogs/DBR77_LAYER_MAP_SUMMARY.csv`
- per-product: `Blogs/<Product>/Blog/00_KNOWLEDGE_LAYER_MAP_01_50.csv`

Generated by:

- `Blogs/_TOOLS/build_catalog_and_layer_maps.py`
