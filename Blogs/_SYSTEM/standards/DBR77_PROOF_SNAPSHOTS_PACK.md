# DBR77 Proof Snapshots Pack

## Purpose

This file defines the proof snapshot units referenced in `Blogs/_OPERATIONS/core/DBR77_FUNNEL_ASSET_MAP.md`.

Use it for:

- company page amplification
- sales follow-up snippets
- decision-stage buyer enablement
- turning long articles into short proof-bearing claims

## Snapshot Format (copy/paste)

Each snapshot should be written in this format:

- **Situation**: what class of plant / org problem is present
- **Signal**: what you see when it is happening
- **Mistake**: what teams do that looks reasonable but fails
- **Fix pattern**: what actually works operationally
- **Outcome logic**: what improves and what risk is reduced
- **Asset anchor**: 1–2 slugs that support the claim
