# DBR77 IIoT — Ścieżka Konwersji (Next Steps)

## 1. Od pierwszego kontaktu do wdrożenia

### Krok 1: Kontakt (chat, formularz, email)

- Klient wyraża zainteresowanie demo lub pilotażem.
- **CTA:** „Zobacz demo online” lub „Zaplanuj pilotaż”.

### Krok 2: Demo online (bez zobowiązań)

- Rejestracja / formularz (imię, firma, email).
- Dostęp do środowiska przykładowego.
- **CTA:** „Chcę pilotaż na mojej linii” lub „Mam pytania — umów rozmowę”.

### Krok 3: RFQ / Zapytanie ofertowe (jeśli nie powstało wcześniej)

- Zebranie wymagań: linia/stanowiska, cele, KPI, źródła danych, łączność.
- **CTA:** „Wyślij zapytanie” / „Umów Discovery”.

### Krok 4: Discovery (30–60 min)

- Spotkanie: cele, KPI, wybór linii, dostępne źródła danych.
- Kwalifikacja Fit/Non-fit.
- **CTA:** „Przejdź do pilotażu” lub „Przygotuj ofertę pilotażową”.

### Krok 5: Oferta pilotażu

- Propozycja zakresu, harmonogramu, kosztów.
- **CTA:** „Akceptuję — podpisuję umowę”.

### Krok 6: Podpisanie umowy

- Umowa pilotażu; warunki płatności.
- **CTA:** „Rozpoczynamy pilotaż”.

### Krok 7: Instalacja i konfiguracja

- Montaż Status Deck / Data Hub.
- Konfiguracja panelu, alertów, ról.
- **CTA:** „Start okresu pomiaru”.

### Krok 8: Okres pomiaru (4–6 tygodni)

- Zbieranie danych; korekty w trakcie.
- **CTA:** „Zakończ pilotaż — wygeneruj raport”.

### Krok 9: Raport końcowy i decyzja o skalowaniu

- Prezentacja wniosków, strat, rekomendacji.
- **CTA:** „Skaluję na całą halę / kolejne linie” lub „Kontynuuję na pilotażu”.

## 2. Call to Action — skrót

| Etap | CTA |
|------|-----|
| Po czacie | „Zobacz demo online” / „Zaplanuj pilotaż” |
| Po demo | „Chcę pilotaż” / „Umów Discovery” |
| Po Discovery | „Przygotuj ofertę” |
| Po ofercie | „Podpisuję umowę” |
| Po pilotażu | „Skaluję” / „Kontynuuję” |
