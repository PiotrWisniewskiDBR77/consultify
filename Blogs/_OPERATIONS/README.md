# Blogs Operations Layer

This folder holds the active operational layer for running, validating, and shipping the DBR77 knowledge-base system.

## Structure

- `core/` contains runbooks, upload packs, activation docs, routing docs, and other operating materials used during execution.
- `image_ops/` contains image-generation operations, queues, logs, QC standards, and image production support documents.

## Main Rule

If a file is part of the repeatable operating system for upload, QA, activation, or image production, it belongs in `_OPERATIONS/`.
