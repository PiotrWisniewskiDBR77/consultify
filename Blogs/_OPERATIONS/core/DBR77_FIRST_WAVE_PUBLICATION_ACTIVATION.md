# DBR77 First Wave Publication Activation

## Purpose

This file turns the completed LP knowledge-base upload into the first live publication and repurposing wave.

Use it after the upload day succeeds.

## Activation Goal

Launch the first authority wave across:

- website LP knowledge bases
- personal expert channels
- DBR77 company page
- email or outbound follow-up

## Wave Order

Use the existing routing queue for the first live sequence:

1. `Consultify`
2. `IoT`
3. `IRIS`
4. `DT`
5. `Marketplace`
6. `Vector`

## Minimum Activation Unit Per Product

Do not call a product wave activated until these five outputs exist:

1. one LP-facing flagship article selected
2. one personal post angle selected
3. one company amplification angle selected
4. one email or nurture angle selected
5. one outbound follow-up snippet selected
