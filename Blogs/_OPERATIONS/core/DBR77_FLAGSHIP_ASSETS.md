# DBR77 Flagship Assets

## Purpose

This file freezes the first six flagship content assets that define quality, tone, structure, and CTA logic for the whole content engine.

Each asset should serve as a reusable standard for future article packages.

## Flagship Set

Topic:
- Why Traditional Consulting Is Broken

- already aligned with existing archived source material
- useful for first contact, nurture, and board-level trust

Primary face:
- Piotr or Torian

## Packaging Rule

Each flagship asset must include:

- `article_EN.md`
- `seo.md`
- `cta.md`
- `image-prompts.md`
- `social.md`
- `sources.md`

## Success Standard

A flagship asset is successful if it can be repurposed into:

- one article
- one personal post
- one company post
- one email angle
- one sales snippet
- one visual prompt set
