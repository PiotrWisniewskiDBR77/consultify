# DBR77 Publication Matrix

## Purpose

This matrix assigns communication ownership by:

- brand face
- product
- persona
- region
- format
- CTA type

Use it to decide who should publish a message before writing the content.

## Channel Logic

- Personal profiles = expertise, point of view, trust, role-specific relevance
- Company page = proof, synthesis, launches, events, category reinforcement
- Website = durable authority, SEO, conversion support
- Email = personalized progression through the funnel

## Publishing Rules

- No face should publish outside their trust zone without a strong reason.
- Personal profiles should sound like experienced humans, not content syndication bots.
- Company page should amplify, summarize, and validate; it should not mirror every personal post word-for-word.
- A product article can be published under a different face only if the persona fit is stronger than the product ownership.
- The same topic can appear in more than one channel only if each version has a different role.
