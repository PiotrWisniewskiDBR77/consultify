# Pakiet odbioru — M17 Materiały (Outputs / Reports & Presentations)

**Nawigacja:** Sidebar → **Raporty** lub **Prezentacje** (RAP hub). Deep-link: `/presentations`, `/reports`.
**Wymóg:** org **nie-demo** + 2 flagi backend ON na demo: `VITE_ENABLE_DELIVERABLES_LIGHT` (build) + `ENABLE_DELIVERABLES_PREMIUM` (backend). Bez nich launcher cichy fallback / `/bundle*` 404.

## Kroki (6)
1. Wejdź w RAP hub. Zakładki: **Wszystkie / Moje / Wymaga przeglądu / Dokumenty / Prezentacje / Arkusze / Dane / Szablony**.
2. **Nowy → „Komplet AI"** (jeśli flaga light ON) — otwiera launcher / czat Teresy z briefem. Podaj temat, uruchom.
3. Poczekaj na wygenerowaną **wiązkę** (raport DOCX + deck PPTX + tabela). → pliki w bibliotece Outputs.
4. Pobierz **ZIP** wiązki. → archiwum z plikami.
5. **★ Zakładka „Dane"** (nowa, T4.3) — wybierz konektor, „Podgląd danych"; albo wpisz ID formularza, „Pobierz zgłoszenia". → dataset renderuje (lub stan pusty fail-soft jeśli brak źródeł).
6. Otwórz deck/raport w podglądzie. → jakość komponowana (M19 PptxPipeline / M18 doc-QA).
