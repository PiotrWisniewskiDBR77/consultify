# Pakiet odbioru — M13 Inicjatywy

**Nawigacja:** Sidebar → **Inicjatywy** (MODULE_INITIATIVES).
**Wymóg:** org **nie-demo**.

## Kroki (6)
1. **Utwórz inicjatywę** (Charter wizard / + Nowa). Wypełnij podstawy, zapisz. → inicjatywa w statusie **DRAFT**.
2. Przełącz na widok **Kanban**. → kolumna **DRAFT** widoczna z Twoją kartą (P1 naprawiony — DRAFT nie znika).
3. Zmień **status** inicjatywy (np. DRAFT→PENDING_REVIEW→...). → status się zmienia, 1 notyfikacja (nie dubel).
4. Otwórz dokument inicjatywy → zakładka **Timeline/Gantt**. → wykres zadań + zależności (`task_dependencies`).
5. Przeciągnij zadanie na Gancie (reschedule). → zapis PUT `/api/pmo/tasks/:id`, UI optymistyczny.
6. **Odśwież (F5)** → status, karty, timeline trwałe.

## Oczekiwane
- Lejek statusów działa, DRAFT widoczny w Kanban, Gantt z jednym źródłem zależności, drag-reschedule.
