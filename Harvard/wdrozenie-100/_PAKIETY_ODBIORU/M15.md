**Nawigacja:** Sidebar → **Resultaty** (MODULE_BENEFITS).
**Wymóg:** org **nie-demo**. Część warstw za flagami URL (default OFF) — dołóż do adresu:
`?ff_valueTree=1&ff_valueScorecard=1&ff_strategicLayer=1&ff_aiInsights=1&ff_portfolioInsights=1&ff_m14Handoff=1`
(np. `https://demo.consultify.ai/...results...?ff_strategicLayer=1&...`).

## Kroki (5-6)
1. Wejdź w **Resultaty**. → lista KPI / dashboard rezultatów (realne dane, caveat: seed).
2. Dodaj/edytuj **KPI** (baseline/target/cadence). → zapis realny (V8).
3. Zobacz **ROI / wartość** — z flagą `ff_valueTree`/`ff_valueScorecard` → drzewo wartości / scorecard renderują.
4. Z flagą `ff_strategicLayer` + `ff_portfolioInsights` → warstwa strategiczna / portfolio insights widoczne.
5. Z flagą `ff_m14Handoff` → **Skrzynka z wdrożenia (M14→Rezultaty)** widoczna (korzyści do promocji na KPI). *(Uwaga: zasilanie skrzynki z M14 = otwarte, patrz B1b T4.1 — skrzynka może być pusta.)*
6. **Odśwież (F5)** z tymi samymi flagami → stan trwały.
