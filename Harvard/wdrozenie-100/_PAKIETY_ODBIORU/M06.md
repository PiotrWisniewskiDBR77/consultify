**Wymóg:** org **nie-demo** (zapis).

## Kroki (5-6)
1. Otwórz ideę → canvas Mapa myśli. Kliknij węzeł root, dodaj **dziecko** (Tab / przycisk +). → nowy węzeł połączony.
2. Dodaj 2-3 kolejne węzły, zmień etykietę (dwuklik), przesuń. → układ trzyma się.
3. Lewy rail: **Cofnij/Ponów** (undo/redo) — wykonaj kilka i cofnij. → stan wraca poprawnie.
4. **Odśwież stronę (F5)** → węzły + krawędzie nadal są (persist, anty-race).
5. Zaznacz węzły → **Konwertuj** (initiative/task_set) → tworzy się cel. → konwersja działa.
6. (opc.) Cmd+K paleta: Timeline / 3D / TimeHeatmap / BatchConvert — osiągalne.
