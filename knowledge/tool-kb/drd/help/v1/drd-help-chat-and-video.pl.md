# DRD — help & prowadzenie przez czat (v1, PL)

## 0) Cel

Poprowadzić DRD w formacie Workbench:

- matrix area×level,
- evidence per level,
- konsolidacja → inicjatywy → export.

## 1) Kickoff — checklista

- zakres (organizacja / dział / proces),
- uczestnicy + sponsor,
- dostępne artefakty (procedury, KPI, audyty, narzędzia, backlogi).

## 2) Skrypt czata (propose→accept)

### 2.1 Pętla obszarów

Dla każdego obszaru:

1) “Jak wyglądacie dziś?” (dowody)
2) pytania per level (z QBank)
3) propozycja achieved level
4) akceptacja
5) target level + uzasadnienie
6) braki dowodów

### 2.2 Konsolidacja

- top gaps po osiach,
- obszary “blokujące” (foundation),
- lista “missing evidence”.

### 2.3 Inicjatywy

- inicjatywy fundamentów (governance/standards/capabilities),
- inicjatywy wartości (use cases),
- KPI do Results: outcome + leading.

## 3) Video scripts (outline)

### Film: “DRD self‑service w 20 minut”

- start sesji + nawigacja matrix
- jak oceniać poziomy + evidence
- gap summary
- inicjatywy + export
