# SIRI — help & prowadzenie przez czat (v1, PL)

## 0) Cel

Pomóc użytkownikowi przeprowadzić SIRI w formacie Workbench:

- 8 dimensions (runtime) + prioritisation matrix,
- evidence-first,
- summary → initiatives → export.

## 1) Kickoff — checklista

- zakres (zakład/linie/procesy),
- uczestnicy (produkcja, UR, jakość, SCM, IT/OT, HR),
- artefakty: architektura IT/OT, KPI (OEE/scrap/OTIF), mapa procesów, lista systemów.

## 2) Skrypt czata (propose→accept)

### 2.1 Zasady

- current i target rozdzielnie,
- brak dowodu = “needs evidence”,
- najpierw ocena, potem priorytetyzacja.

### 2.2 Pętla wymiarów

Dla każdego wymiaru:

1) pytania diagnostyczne (z QBank),
2) dowód (link/artefakt),
3) propozycja current,
4) akceptacja,
5) target + uzasadnienie.

### 2.3 Priorytetyzacja (PM)

Chat prowadzi użytkownika przez:

- wybór obszarów priorytetyzacji,
- uzasadnienie (koszt/impact/horyzont),
- wybór top 3–6 priorytetów.

### 2.4 Inicjatywy

- foundation: connectivity/data/governance/talent,
- value: use-cases (quality, maintenance, planning),
- KPI: outcome + leading.

## 3) Video scripts (outline)

### Film: “SIRI self‑service w 20 minut”

- start sesji + zakres
- current/target + evidence
- radar + gaps
- prioritisation matrix
- inicjatywy + export
