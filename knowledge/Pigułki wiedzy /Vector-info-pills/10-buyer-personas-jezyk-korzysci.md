## 1. How to Use This Document

This file translates DBR77 Vector capabilities into **persona-specific value language**.

Use it to:
- tailor messaging per role
- handle objections with precision
- accelerate qualification and conversion

Each persona includes:
- **Profile**
- **Top 3 Hooks (sales openers)**
- **Unique Value (table)**
- **Language to Avoid**

---

## 2. Persona 1: CEO / Owner / President

### Profile
- Focus: growth, ROI, risk
- Pain: unclear decisions, slow execution, CAPEX risk

### Top 3 Hooks
> “You’re making million-dollar decisions with incomplete data.”
> “Vector reduces decision risk before you commit CAPEX.”
> “Faster decisions = faster growth.”

### Unique Value

| Area | Value |
|------|------|
| Strategy | Data-backed decisions |
| Finance | Lower CAPEX risk |
| Speed | Faster execution |

### Language to Avoid
- “AI model”
- “inference latency”
- “GPU optimization”
