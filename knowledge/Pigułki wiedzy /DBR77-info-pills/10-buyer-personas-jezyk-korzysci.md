## 1. How to Use This Document

This file translates the DBR77 Ecosystem into **persona-specific value language** across products (Consultify, IoT, IRIS, Digital Twin, Marketplace, Vector).

Use it to:
- route prospects to the right entry gate
- tailor messaging per role
- accelerate qualification and conversion

Each persona includes:
- **Profile**
- **Primary Entry Gates**
- **Top 3 Hooks (sales openers)**
- **Value by Product (table)**
- **Language to Avoid**

---

## 2. Persona 1: CEO / Owner / President

### Profile
- Focus: growth, ROI, risk, strategic clarity
- Pain: fragmented systems, slow execution, uncertain CAPEX

### Primary Entry Gates
- Consultify
- Digital Twin

### Top 3 Hooks
> “You’re making multi-million decisions without system visibility.”
> “DBR77 reduces decision risk before you commit CAPEX.”
> “Build a system that improves performance year over year.”

### Value by Product

| Product | Value |
|--------|------|
| Consultify | Transformation governance, ROI clarity |
| Digital Twin | CAPEX de-risking |
| Vector | Decision intelligence |
| IRIS | Execution alignment |
| IoT | Operational visibility |
| Marketplace | Better sourcing decisions |

### Language to Avoid
- “features”, “model size”, “GPU”
