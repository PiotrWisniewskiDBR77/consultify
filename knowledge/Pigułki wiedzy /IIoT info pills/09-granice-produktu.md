# DBR77 IIoT — Granice Produktu (Out-of-scope)

## 1. Czego DBR77 IIoT NIE jest i czego NIE robi

| Obszar | Opis |
|--------|------|
| **Sterowanie maszynami** | Nie steruje maszynami; zbiera dane i wyświetla je. Sterowanie pozostaje w PLC/SCADA. |
| **Zastąpienie fizycznego BHP** | Vision AI wspomaga wykrywanie PPE; nie zastępuje procedur, szkoleń i audytów BHP. |
| **Wdrażanie robotów** | Nie montuje ani nie programuje robotów; może monitorować ich pracę. |
| **ERP** | Nie zastępuje ERP; może integrować się z ERP. |
| **Pełny MES** | IIoT to warstwa danych i OEE; pełny MES jest w IRIS (osobny produkt). |
| **Gwarancja fizycznego bezpieczeństwa** | System nie gwarantuje braku wypadków; wspiera monitorowanie i alerty. |
| **Doradztwo strategiczne** | Nie zastępuje konsultacji strategicznych; dostarcza dane do decyzji. |
| **Legal / Compliance** | Nie zapewnia pełnej zgodności prawnej (np. RODO); wspiera techniczne aspekty. |
| **Sprzęt niestandardowy** | Nie produkujemy na zamówienie unikalnych urządzeń; oferujemy zestaw z katalogu. |
| **Trening modeli AI na danych klienta** | Nie trenujemy modeli AI na danych procesowych klienta bez wyraźnej zgody. |
