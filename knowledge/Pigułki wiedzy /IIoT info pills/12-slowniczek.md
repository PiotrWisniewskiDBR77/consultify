# DBR77 IIoT — Słowniczek Pojęć Branżowych (Glossary)

| Termin | Definicja |
|--------|-----------|
| **OEE (Overall Equipment Effectiveness)** | Kluczowy wskaźnik efektywności maszyn: Availability × Performance × Quality. Mierzy wykorzystanie maszyn w czasie, wydajność i jakość. |
| **Status Deck** | Urządzenie DBR77 do deklaracji stanu maszyny: Praca / Przerwa / Przezbrojenie / Awaria. |
| **Data Hub / Master** | Bramka DBR77 montowana na szynę DIN; zbiera sygnały z PLC, czujników; multi-protokół (MQTT, Modbus, RS485). |
| **The Loop** | Architektura DBR77 IIoT: źródła danych → edge → panel → akcja (mobile/tablet) → optymalizacja. |
| **Edge** | Przetwarzanie danych na urządzeniu lub bramce, blisko źródła — bez wysyłania wszystkich danych do chmury. |
| **Walidacja sygnałów** | Analiza i wnioskowanie o poprawności danych (format, zakres, typ) przed transmisją dalej. |
| **Modbus** | Protokół przemysłowy do komunikacji z PLC i urządzeniami; RTU (szeregowy) i TCP (ethernet). |
| **MQTT** | Lekki protokół publikacji/subskrypcji; popularny w IoT. |
| **RS485** | Standard komunikacji szeregowej w środowisku przemysłowym. |
| **LoRaWAN** | Sieć dalekiego zasięgu (LPWAN) dla urządzeń IoT; niskie zużycie energii. |
| **Retrofit** | Dostosowanie starszych maszyn do zbierania danych bez wymiany infrastruktury. |
| **Industry 4.0** | Czwarta rewolucja przemysłowa — cyfryzacja produkcji, IoT, AI. |
| **Vision AI** | Moduł DBR77: przetwarzanie obrazu na edge (BHP/PPE, QA, anomalie). |
| **Pilotaż** | Test wdrożenia na 1–3 stanowiskach lub jednej linii; raport z wnioskami. |
| **Pareto (analiza)** | Identyfikacja głównych przyczyn strat (80/20); priorytetyzacja działań. |
| **Eskalacja** | Automatyczne przekazanie alertu do wyższej roli przy braku reakcji. |
| **CE** | Certyfikacja zgodności z wymogami UE dla urządzeń. |
| **ISO 27001** | Międzynarodowy standard zarządzania bezpieczeństwem informacji. |
| **IRIS** | Szersza platforma DBR77 — Plant Operating System; IIoT jest jej warstwą danych. |
| **Digital Twin** | Cyfrowa replika procesu lub maszyny; symulacje i analiza (w IRIS). |
