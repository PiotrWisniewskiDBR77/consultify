# AI Streaming Protocol Specification (SSE)

**Last Updated:** 1 January 2026  
**Reference Hook:** `hooks/useAIStream.ts`  
**Reference Route:** `POST /api/ai/chat/stream`

This document defines the Server-Sent Events (SSE) protocol used for real-time AI interactions in Consultinity. Adherence to this protocol is mandatory for all frontend-to-AI-gateway communications.

---

## 1. Connection Standards
- **Endpoint**: `POST /api/ai/chat/stream`
- **MIME Type**: `text/event-stream`
- **Authentication**: Bearer Token required.
- **Headers**:
  ```http
  Content-Type: text/event-stream
  Cache-Control: no-cache
  Connection: keep-alive
  ```

---

## 2. Event Payload Structure

The stream emits JSON-encoded data strings prefixed with `data: `. Every event must be parsed as a JSON object.

### Type: `thought`
Emitted as the AI Pipeline processes internal stages (e.g., searching, analyzing). Useful for "Thinking Visualization".
```json
{
  "type": "thought",
  "stage": "research | analysis | synthesis | validation",
  "detail": "Detailed description of the current internal operation",
  "timestamp": "ISO-8601 String"
}
```

### Type: `text`
Standard response chunk for incremental UI rendering.
```json
{
  "text": "The incremental text chunk generated by the model."
}
```

### Type: `error`
Terminal event emitted if a provider fails or a quota is exceeded.
```json
{
  "error": "Error message description",
  "code": "quota_exceeded | provider_failure | security_block"
}
```

### Terminal Marker: `[DONE]`
Sent when the stream is completed successfully.
```
data: [DONE]
```

---

## 3. Inline Structured Content

### Thinking Blocks (deprecated in favor of `thought` event)
Older models may emit text-based thinking blocks which the frontend must strip from content:
```xml
<thinking>
1. Analyze user intent
2. Search knowledge base
</thinking>
```

### Artifact Detection
The stream may contain "Artifacts" (code blocks, diagrams, documents) delimited by custom markers:
```markdown
:::artifact{type="diagram" title="System Flow"}
graph TD; A-->B;
:::
```
The `hooks/useAIStream.ts` is responsible for parsing these during the stream and updating the `useArtifactsStore`.

---

## 4. Resilience Patterns
1. **Model Fallback**: The backend handles multi-provider fallback. The frontend should NOT reconnect or retry; it should wait for the backend to switch providers and continue the stream or emit an error.
2. **Buffer Management**: Frontend hooks use `contentRef` to accumulate chunks, ensuring that React re-renders do not lose data during high-velocity streams.
