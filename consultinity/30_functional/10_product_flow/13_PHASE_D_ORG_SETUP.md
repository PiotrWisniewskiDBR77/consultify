# PHASE D — ORGANIZATION SETUP

## 1. Strategic Intent
| Dimension | Definition |
|-----------|------------|
| **Business Goal** | Transform user→customer to org→partner. |
| **User Perception** | "I'm founding a decision space, not buying a subscription." |
| **Success Metric** | Organizational ownership felt. |

## 2. User Journey Workflow
1. **Initiation**: Transition from Trial requires explicit 3-point consent (Time commitment, Permanent space, Stakeholder consideration).
2. **Identification**: User defines "Organization Name" (e.g., "Strategy Unit - London").
3. **Role Alignment**: User selects their role (Executive, Director, Consultant, etc.) to shape AI behavior.
4. **Context Mapping**: Definition of industry, size, and operating model (Operating vs. Consulting).
5. **Memory Activation**: Explicit activation of persistent memory graph.

## 3. Technical Implementation
- **AI Mode**: **MEMORY**. Activates persistent context, initializes decision graph, and adopts organizational personality.
- **Data Model**: Transition from single `User` identity to `Organization` entity with UUID v4.
- **Intentional Slowness**: Setup workflow designed to take > 2 minutes to enforce deliberate decision-making.

## 4. Quality Checklist
- [x] Each step requires conscious input (no defaults).
- [x] Memory activation requires explicit consent.
- [x] Language used is "Founding/Activating", not "Signing up".
- [x] Progress indicator visible throughout the 4-step process.
