# PHASE G — ECOSYSTEM PARTICIPATION

## 1. Strategic Intent
| Dimension | Definition |
|-----------|------------|
| **Business Goal** | Turn successful organizations into network referrers. |
| **User Perception** | "I can help my network solve similar problems while gaining value." |
| **Success Metric** | Positive Viral Coefficient (K > 0). |

## 2. User Journey Workflow
1. **Advocacy**: Organization reaches "Done" status on critical initiatives.
2. **Referral Creation**: Admins generate "Ecosystem Invitation Codes" for partners/clients.
3. **Transparency**: Reward/Referral tracking visibility.
4. **Knowledge Sharing**: (Optional) Participation in anonymized cross-org benchmark pools.

## 3. Technical Implementation
- **AI Mode**: **MATCHMAKER**. Recommends connections or similar (anonymized) case studies.
- **Affiliate Engine**: Tracking of Code usage and organization conversion.

## 4. Quality Checklist
- [x] Referral codes are high-value (selective), not spammy.
- [x] Absolute data privacy between referral-linked organizations.
- [x] Clear "Advocacy" dashboard for management.
