# PHASE A — PRE-ENTRY (PUBLIC)

## 1. Strategic Intent
| Dimension | Definition |
|-----------|------------|
| **Business Goal** | Quality filter, not lead capture. |
| **User Perception** | "These people understand the problem deeply." |
| **Success Metric** | Category comprehension in < 60 seconds. |

## 2. User Journey Workflow
1. **Entry**: User visits landing page.
2. **Engagement**: User reads "North Star Statement" and "Problem Narrative".
3. **Internalization**: User identifies with the structural problem described.
4. **Action**: User clicks single CTA "Zobacz, jak to działa".

## 3. Technical Rules
- **AI Behavior**: **SILENT**. No AI references or interactions.
- **Data Capture**: **NONE**. No forms, no tracking pixels (restraint as trust signal).
- **UI Constraints**: Serif headlines for authority. No gradients or aggressive colors.

## 4. Quality Checklist
- [x] Zero forms visible.
- [x] Zero AI/ML/automation language.
- [x] Single CTA only.
- [x] WCAG 2.1 AA compliant.
