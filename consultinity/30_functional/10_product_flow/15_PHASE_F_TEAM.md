# PHASE F — TEAM EXPANSION

## 1. Strategic Intent
| Dimension | Definition |
|-----------|------------|
| **Business Goal** | Organic MAU growth via decision complexity. |
| **User Perception** | "This decision needs more perspectives; I must invite the team." |
| **Success Metric** | Average 3+ perspectives per DRD axis. |

## 2. User Journey Workflow
1. **Trigger**: AI detects "Perspective Gap" (e.g., "The Finance view is missing on this Tech axis").
2. **Invitation**: User invites team members with a specific "Reason" (e.g., "Need your view on cash flow constraints").
3. **Contribution**: New users add their "Positions" to existing axes.
4. **Synthesis**: AI Facilitator surfaces differences and points for discussion.
5. **Action**: Team moves from alignment to "Initiative Execution" (Task management).

## 3. Technical Implementation
- **AI Mode**: **FACILITATOR**. Identifies patterns, synthesizes views, never takes sides or resolves conflict.
- **Access Control**: Role-based (Admin, Member, Viewer, External Advisor).
- **Notifications**: "Tension Detected" notifications to relevant stakeholders when divergent positions are mapped.

## 4. Quality Checklist
- [x] AI mode restricted to neutral synthesis.
- [x] Invitations include the context of the specific decision.
- [x] Audit trail captures all changes to axes and positions.
- [x] Multi-user conflict resolution UI implemented.
