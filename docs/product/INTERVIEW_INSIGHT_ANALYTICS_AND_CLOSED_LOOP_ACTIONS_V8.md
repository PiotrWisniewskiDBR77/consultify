# Interview Insight Analytics And Closed Loop Actions v8

> Status: Draft v8
> Owner: Product + Engineering
> Scope: analytics layers, cross-session rollups, contradiction handling and governed handoff from Interview findings into change-management work

---

## 1. Why this document exists

Interview should not stop at answer capture.

It must convert findings into:

- insight
- action
- governed follow-up

---

## 2. Analytics layers

The module should support:

- session-level analytics
- wave-level analytics
- program-level analytics
- executive synthesis

---

## 3. Insight model

Insights should distinguish:

- signal
- theme
- contradiction
- evidence-backed finding
- assumption
- unresolved gap

Important insights should also preserve:

- evidence class
- confidence level
- triangulation state

---

## 4. Closed-loop action doctrine

Interview findings should be able to produce:

- initiative input
- task
- decision candidate
- risk note
- knowledge object
- clarification follow-up
- targeted re-interview

Rule:

`important findings should not die as passive transcript content`
