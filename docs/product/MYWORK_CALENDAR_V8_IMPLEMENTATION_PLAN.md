# MyWork Calendar v8 - Implementation Plan

> Status: Draft v8
> Owner: Product + Engineering
> Scope: wave-by-wave documentation plan for turning the current calendar baseline into a PMO-grade calendar with Outlook and Google synchronization

---

## 1. Strategic intent

The goal is to make the calendar the real time operating surface for transformation work.

That means:

- one unified time model
- real Outlook and Google integration
- PMO timing depth
- workload awareness

---

## 2. Waves

### Wave A - Product convergence

Goal:

- align `V1` calendar, current runtime and `V8` target

Deliverables:

- final V8 SSOT
- honest current-state interpretation
- one canonical event model

### Wave B - External sync baseline

Goal:

- establish trustworthy Outlook and Google support

Deliverables:

- OAuth lifecycle
- external event merge
- source-aware filters
- sync health visibility

### Wave C - PMO item expansion

Goal:

- add missing planning item classes

Deliverables:

- assignments
- adjustments
- approval windows
- escalation timing

### Wave D - Conflict and authority model

Goal:

- make calendar moves safe and explainable

Deliverables:

- source-of-truth rules
- reschedule authority
- conflict surfaces

### Wave E - Workload and overload intelligence

Goal:

- move beyond date display into PMO planning quality

Deliverables:

- workload overlays
- overload insights
- review density awareness
- AI scheduling assistance

---

## 3. Definition of done

Calendar v8 is ready when:

- internal and external time items live under one model
- Outlook and Google integration are honest and real
- PMO timing classes are first-class
- workload and conflict behavior are explicit
