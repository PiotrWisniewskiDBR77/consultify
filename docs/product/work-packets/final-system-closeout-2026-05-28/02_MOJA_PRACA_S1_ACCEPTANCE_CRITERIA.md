# 02 Moja Praca - S1 Acceptance Criteria

Status: `in_progress`

Module: `02 Moja Praca`

---

## Acceptance criteria (must pass)

1. User can open My Work and load primary cockpit data.
2. Core operational shortcuts/actions from My Work are functional.
3. In-scope stateful actions persist and survive refresh.
4. Main action paths have no dead primary action.
5. Error/degraded/empty states are explicit and honest.
6. No raw internals are displayed in user-facing UI.
7. Security and role boundaries are respected for visible actions/data.
8. Gate decision is backed by UI/API/refresh evidence.

---

## Pass thresholds

- No open P0/P1 in core My Work workflow.
- Residual P2 only with owner and follow-up.
- Security/tenant checks pass for in-scope paths.
