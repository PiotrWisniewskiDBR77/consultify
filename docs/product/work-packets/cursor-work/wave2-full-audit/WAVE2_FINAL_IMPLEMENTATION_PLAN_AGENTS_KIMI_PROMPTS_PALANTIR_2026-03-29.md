# Wave 2 Final Implementation Plan - Agenci / KIMI / Prompty / Palantir

Date: 2026-03-29
Module: `Agenci / KIMI / Prompty / Palantir`
Scope: final implementation plan for the visible Wave 2 AI operating-system family

## 1. Scope

This plan covers only the combined AI OS family:

- `Agenci`
- `KIMI-style artifact-native behavior`
- `Prompty`
- `Palantir-like governed knowledge truth`

It does not widen scope into:

- every chat feature in the product
- full standalone implementation of names such as `KIMI` or `Palantir` as separate modules
- hiding broad AI debt behind strong internal doctrine

## 3. Benchmark Family From `Softs`

Primary benchmark family:

- visible AI operating systems, governed prompt platforms, and knowledge-truth systems with agent coordination and artifact-native behavior

Benchmark interpretation:

- one visible AI family matters more than scattered features
- prompts should behave like governed platform assets
- knowledge truth should be policy-aware and traceable
- artifact-native behavior should be explicit, not implied

## 4. Intended Final Product Behavior

This family should behave like one visible AI operating system:

- one map of what AI can do
- one visible agent work model
- one governed prompt lifecycle
- one policy-aware knowledge truth model tied to execution and outputs

## 5. Current Repo Truth

What is already true:

- doctrine and planning around AI are strong
- agent, pipeline, and prompt infrastructure are materially real
- artifact-native and knowledge-truth directions are documented

What is still incomplete:

- the user-facing suite is not yet one obvious product family
- prompt and knowledge truth are stronger as infrastructure than as packaged capability
- `KIMI` and `Palantir` act more like benchmark directions than visible product contracts

## 8. Dependencies And Risks

Dependencies:

- `Landing`
- artifact family and outputs
- prompt OS and knowledge layers
- execution and work surfaces that receive AI output

Risks:

- calling infrastructure maturity a finished product
- using benchmark names without converting them into behaviors
- collapsing many AI surfaces into one vague umbrella without bounded packets

## 9. Final Acceptance Bar

`Agenci / KIMI / Prompty / Palantir` is finally implemented for its declared Wave 2 role only when:

- the AI family has one visible operating-system identity
- agent work, prompt governance, and knowledge truth are explicitly related
- artifact-native behavior is visible in the product story
- benchmark references are translated into concrete user-facing behaviors

## 10. Non-Goals And Unsafe Claims

Non-goals:

- one-shot parity with every AI leader
- separate branded products for `KIMI` or `Palantir`
- full autonomous-agent platform completion

Unsafe claims until separately proven:

- `the complete AI operating system is already built`
- `prompt governance and knowledge truth are fully productized everywhere`
- `agent parity with category leaders is achieved`
