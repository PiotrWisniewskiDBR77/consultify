This plan covers only the broader `Pelny Reports / Presentations builder` ambition for richer authoring depth.

- replacing the artifact family or library work
- pretending current generated-first flows already equal full builder maturity
- a hidden full editor rewrite without bounded packets

## 3. Benchmark Family From `Softs`

Primary benchmark family:

- office-style report and presentation authoring systems with rich editing, durable drafts, and controlled delivery workflows

Benchmark interpretation:

- generate is not enough
- users need meaningful restructure and continuation ability
- richer authoring should still preserve governance and artifact truth

## 4. Intended Final Product Behavior

`Pelny Reports / Presentations builder` should represent the broader authoring horizon:

- generate into durable drafts
- edit and restructure meaningfully
- continue work over time
- review and deliver without leaving the governed artifact family

## 5. Current Repo Truth

What is already true:

- strong generated-first runtime already exists for documents and decks
- builder ambition is documented and explicit

What is still incomplete:

- rich authoring depth is still materially behind the broad ambition
- current runtime is stronger as governed generation than as full builder product
- this area should come after family stabilization, not before it

## 8. Dependencies And Risks

Dependencies:

- `Outputs Library`
- `Documents`
- `Presentations`
- `ArtifactRun z czatu`
- `Provenance / review / visibility`

Risks:

- opening a hidden rewrite before the artifact family is stable
- claiming builder parity from generated-first strength
- letting authoring depth break trust and traceability semantics

## 9. Final Acceptance Bar

`Pelny Reports / Presentations builder` is finally implemented for its declared Wave 2 role only when:

- the builder ambition is bounded and explicit
- at least one rich authoring lane is materially deeper than generation-only behavior
- durable drafts and continuation are believable
- deeper authoring still respects artifact-family governance

## 10. Non-Goals And Unsafe Claims

Non-goals:

- full Google Docs plus PowerPoint parity
- complete collaboration suite parity
- replacing the stabilized artifact family with a new editing paradigm

Unsafe claims until separately proven:

- `the full office-style builder is now complete`
- `rich authoring now matches category leaders`
- `generation-first and builder-grade maturity are equivalent`
