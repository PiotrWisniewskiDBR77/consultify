Date: 2026-03-29
Module: `Tools`
Scope: final implementation plan for the broad consulting-tools product canon beyond the current bridge-heavy truth

## 1. Scope

This plan covers only broad `Tools` as the consulting-tools product family.

It does not widen scope into:

- every specialist tool in the market
- replacing `Assessment` as its own module family
- treating V3 or bridge truth as already equal to full Tools v8 closure

## 3. Benchmark Family From `Softs`

Primary benchmark family:

- consulting tool libraries and guided workspaces with clear discovery, session logic, and output promotion

Benchmark interpretation:

- discover tools clearly
- run one coherent session model
- keep AI governed inside the session
- turn outputs into durable downstream work

## 4. Intended Final Product Behavior

`Tools` should behave like one consulting-tools product:

- clear library and selection grammar
- one preferred session model
- visible AI governance
- outputs promoted into downstream artifacts and work objects

## 5. Current Repo Truth

What is already true:

- V3 and bridge truth are materially real
- discovery/tool surfaces already exist

What is still incomplete:

- one refreshed Tools v8 canon is still missing
- the family is stronger as accumulated truth than as one clear product contract
- library-session-output continuity still needs one execution-grade package

## 8. Dependencies And Risks

Dependencies:

- `Assessment`
- artifact family and outputs
- help and AI prompt layers

Risks:

- leaving Tools as a perpetual bridge program
- overfitting the family to one tool instead of one shared grammar
- confusing strong docs with finished product closure

## 9. Final Acceptance Bar

`Tools` is finally implemented for its declared Wave 2 role only when:

- one clear Tools v8 canon exists
- library, session, and output flow are coherent
- AI use inside the family is visibly governed
- the family is no longer described only through V3 inheritance or bridge language

## 10. Non-Goals And Unsafe Claims

Non-goals:

- every consulting methodology in one wave
- full feature parity against broad specialist tool suites
- collapsing `Assessment` back into generic tools

Unsafe claims until separately proven:

- `Tools now fully matches category leaders`
- `all tool families are unified at full parity`
- `bridge truth already solved the full product canon`
