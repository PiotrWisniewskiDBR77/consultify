## Delivered scope

### DB Migration (`20260331_p26b_kb_collections_tags_surfaces.sql`)
- `kb_collections` + `kb_collection_translations` — IA spine with nested hierarchy, visibility, featured
- `kb_tags` + `kb_tag_translations` — cross-cutting facets (domain/tool/concept/stage/audience), synonyms, deprecation+redirect
- `kb_article_collections` — article ↔ collection junction
- `kb_article_tags` — article ↔ tag junction
- `kb_surface_bindings` — explicit "where content appears" (lp/help/right_panel/ai_recommendations/public_docs) + tool_context
- `kb_article_versions` — audit trail (version, change_type, change_note)
- `kb_sources` + `kb_article_sources` — evidence pointers
- Extended `kb_articles`: canonical_topic_key, visibility, deprecated_at, deprecation_reason, replacement_article_id, redirect_to_article_id, owner_user_id, review_cadence_days, review_due_at, version, related_article_ids, callouts
- Backfill: existing categories → collections, existing articles → default surface bindings

### Backend (`KnowledgeBaseService` + V8 routes)
- Collections: getCollections, getCollectionBySlug, getArticlesByCollection
- Tags: getTags, getArticlesByTag
- Faceted search: searchWithFacets (query + collection + tags + surface filter, returns articles + collection/tag facets)
- Related articles: getRelatedArticles (curated, bounded)
- Versions: getArticleVersions
- Deprecation/redirect: resolveArticleRedirect
- Surface bindings: getArticlesForSurface (surface + toolContext)
- V8 public routes: /collections, /collections/:slug, /collections/:slug/articles, /tags, /tags/:slug/articles, /search/faceted, /articles/:slug/related, /articles/:slug/versions, /articles/:slug/redirect, /surface/:surface

### Frontend
- KnowledgeLibrary: collection-first browse (CollectionCard), tag facet chips (TagChip), faceted search with collection/tag refinement, collection breadcrumb, empty collection fallback
- KnowledgeArticleView: deprecation banner with replacement link, related articles section, redirect handling
- useKnowledge hooks: useKnowledgeCollections, useKnowledgeCollectionArticles, useKnowledgeTags, useKnowledgeRelated, useKnowledgeRedirect, useKnowledgeSearchFaceted

### AI Grounding
- helpDocsContext: surface binding filter added, priority ordering (surface-bound > contextual > search), `surface` parameter support

### Tests
- 25 integration tests covering all new endpoints + regression for existing ones

## Known limits (operational, not contract gaps)
- Content seeding (50 articles target) is an ops/editorial task, not code
- Full-text search is LIKE-based (no FTS/tsvector index) — adequate for current scale
- Chart/visual content in articles not supported (markdown + images only)
- Tag synonyms stored but not yet used in search expansion
