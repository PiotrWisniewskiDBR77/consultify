# TBL-FU-5 — Formula And Automation Engine

**Priority:** P2  
**Owner:** Table Platform  
**Source:** Table Studio Foundation closeout

## Goal

Define and implement formula/computed-column explanation and automation primitives for operational Tabele artifacts.

## Acceptance Criteria

- Formula behavior has explicit validation, error taxonomy, and dependency impact preview.
- Automation actions are proposal-governed where they mutate schema or high-impact data.
- Explanations are visible in the Tabele document canvas.
- No hidden learning or hidden writes are introduced.
