# TBL-FU-4 — Proposal Review Queue In Canvas

**Priority:** P2  
**Owner:** Frontend / Governance UX  
**Source:** Table Studio Foundation closeout

## Goal

Add a dedicated, governed review queue surface for Tabele schema proposals inside the document canvas without adding hidden execution.

## Acceptance Criteria

- Proposal rows show status, target, summary, created actor, and audit trail link.
- Approval/rejection requires explicit user action and never auto-executes.
- AI action placement follows Menu 3/right command slot rules.
- Tenant/ACL checks are preserved on every proposal read/mutation.
