- accepted bounded work already closed the smaller analyses/runtime-truth slices
- forcing a code packet first would risk silently merging broader finance breadth into one pseudo-small rewrite

### Packet scope

- document the current broader finance residual after the accepted bounded `T2` lane
- identify where active finance surfaces, governed V8 analyses seams, and wider legacy-backed finance flows still diverge
- name the smallest real follow-on packet only after that residual is explicit
- keep this packet evidence-first rather than pretending the broader finance slice is already chosen

This broader lane is not done after one map.

1. the remaining broader `Finance` residuals are broken into honest bounded packets,

3. no smaller real packet remains,
