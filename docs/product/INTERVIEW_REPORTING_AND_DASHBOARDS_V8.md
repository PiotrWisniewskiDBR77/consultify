# Interview Reporting And Dashboards v8

> Status: Draft v8
> Owner: Product + Engineering
> Scope: session, wave, program and executive reporting layers plus dashboard semantics for Interview

---

## 1. Why this document exists

Interview needs stronger reporting than raw answer browsing.

---

## 2. Reporting layers

The module should provide:

- session report
- wave dashboard
- program dashboard
- executive summary view

---

## 3. Dashboard themes

Dashboards should surface:

- completion and drop-off
- theme density
- contradiction clusters
- evidence sufficiency
- confidence distribution
- triangulation status
- missing stakeholder coverage
- respondent coverage
- action readiness

---

## 4. Export and presentation link

Interview reporting should support:

- internal review
- leadership readout
- downstream report generation
- presentation input
