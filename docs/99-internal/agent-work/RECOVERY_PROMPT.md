# PROMPT DO WKLEJENIA W WĄTKI CURSOR

Skopiuj poniższy tekst i wklej na początku wątku gdzie był tworzony kod:

---

## 🚨 RECOVERY MODE

**Utracono kod z tego wątku** z powodu błędu git (lint-staged stash + git clean).

**Twoje zadanie:**
1. Przeczytaj CAŁĄ historię tego wątku
2. Znajdź kod który był tworzony/modyfikowany
3. Odtwórz go w odpowiednich plikach
4. **PO KAŻDYM PLIKU** wykonaj commit:
   ```bash
   git add [plik] && git commit -m "recover: [nazwa]"
   ```

**Pełna lista utraconych plików:** `docs/99-internal/agent-work/RECOVERY_INSTRUCTION.md`

**ZASADY:**
- NIE używaj `git reset --hard`
- NIE używaj `git clean`
- Commituj CO PLIK - nie czekaj
- Jeśli nie pamiętasz dokładnie kodu - napisz nową implementację bazując na kontekście wątku

**Zacznij od przeczytania historii wątku i odtworzenia kodu.**
