# Help AI Journey Video Catalog

## Purpose
This catalog contains short micro-video scenarios aligned with the new Help Center narrative:
- `Interview`
- `Tools + Assessments`
- `Initiatives`
- `Execution`
- `Results`
- support modules with constant AI presence

All videos are designed for:
- `30-45 sec`
- fast onboarding at module entry
- clear handoff to `Ask AI now`
- short, concrete, action-oriented narration

## Production Standard
- Language: `PL`
- Format: avatar + screen capture + UI callouts
- Goal: user should understand in under 10 seconds where they are, why this place exists, what to do next, and how AI helps now
- End every video with a soft CTA: `Przejdź dalej` or `Zapytaj AI teraz`

## Reuse Rule
When a module changes, update only the matching scenario file and keep:
- opening promise
- 3-part flow
- AI CTA
- 45-second cap
