# Cards & grids (view mode)

## Purpose

Ujednolicić zasady użycia kart/grid jako alternatywnego view mode dla tej samej kolekcji danych.

## Applies To

Ekrany hub/list, które oferują view mode `grid`.

## Must

- **MUST**: `grid/cards` nie zastępuje App Table jako kanonicznego widoku rekordów operacyjnych.
- **MUST**: Karta ma stabilną anatomię (meta → title → signals → actions) i nie dokłada lokalnych toolbarów.
- **MUST**: Akcje są spójne z tabelą (kebab/row actions semantics).
