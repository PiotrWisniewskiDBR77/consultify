# Accessibility standard (baseline)

## Purpose

Zamknąć minimalny standard dostępności (keyboard, focus, contrast), żeby UI było używalne i testowalne.

## Applies To

Cała aplikacja.

## Must

- **MUST**: UI jest obsługiwalne klawiaturą (tab order, focus visible, esc/enter w dialogach).
- **MUST**: Kontrast tekstu i elementów UI spełnia minimum (WCAG AA jako baseline).
- **MUST**: Stany (error/disabled/locked) nie opierają się wyłącznie na kolorze.
