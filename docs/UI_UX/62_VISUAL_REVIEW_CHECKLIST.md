# Visual review checklist (baseline)

## Purpose

Dać powtarzalną checklistę przeglądu wizualnego dla ekranów (dark/light, spacing, stany, overflow), żeby “beauty i trust” były weryfikowalne.

## Applies To

Nowe ekrany, refaktory UI, naprawy P0/P1.

## Must

- **MUST**: Sprawdzić dark + light mode (czytelność, kontrast, separatory, brak “wyprania” w light mode).
- **MUST**: Sprawdzić stany: empty/loading/success/error/degraded.
- **MUST**: Sprawdzić brak duplikacji toolbarów (Menu 2/3 i żadnych dodatkowych pasków).
- **MUST**: Sprawdzić CTA: jeden primary CTA, bez gradientów w operational chrome, bez mieszania rodzin kontrolek.

## Should

- **SHOULD**: Porównać do referencji (golden standard screens / evidence pack).
