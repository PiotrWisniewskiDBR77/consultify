# Plans Directory

This directory contains working plans, delivery packets, and historical planning exports.

## Authority

- `docs/product/` holds product SSOTs and readiness packages.
- `docs/strategy/` holds canonical strategy packages and strategic execution references.
- `docs/plans/` holds working and historical planning material that may support implementation, but is not automatically a product source of truth.

## Subareas

| Path | Role |
| --- | --- |
| `docs/plans/v2-delivery/` | tracked delivery packets and execution prompts |
| `docs/plans/v2-packs/` | bundled planning material |
| `docs/plans/chatgpt-export/` | historical ChatGPT export artifacts kept for reference |

## Rules

- non-suffixed files are preferred over local Finder/iCloud numbered copies
- planning exports should be kept in one place, not duplicated across trees
- when a plan becomes product doctrine, the canonical destination is usually `docs/product/` or `docs/strategy/`
