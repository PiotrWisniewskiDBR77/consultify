# Export V2_TASK_SPECS dla ChatGPT

**Jak używać:**

1. **Opcja A — całość (jeśli model ma duży kontekst):**
   - Otwórz `V2_TASK_SPECS_FULL.md`
   - Skopiuj całość (Ctrl+A, Ctrl+C) i wklej do ChatGPT

2. **Opcja B — w 3 częściach (zalecane dla większości modeli):**
   - Wklej **PART1** → napisz: „Oto część 1 (T001–T040). Mam też części 2 i 3.”
   - Wklej **PART2** → napisz: „Oto część 2 (T041–T080).”
   - Wklej **PART3** → napisz: „Oto część 3 (T081–T122). Teraz masz pełną specyfikację.”

**Instrukcja dla ChatGPT (wklej na początku rozmowy):**
```
Masz specyfikację 122 tasków rozwoju aplikacji Consultify V2. Każdy task ma: business challenge, cel, scope (IN/OUT), DoD, acceptance criteria. Użyj tej specyfikacji do [analiza / planowanie / implementacja / review] — doprecyzuj w rozmowie, co mam zrobić.
```
