# Purpose — Meeting

## Purpose

Zdefiniować po co istnieje Meeting: zamienić przebieg spotkania w uporządkowane notatki + decyzje + zadania z traceability do Initiative/My Work, bez udawania pełnego “calendar suite”.

## Must

- MUST: przechwytywać decyzje i action items w formie możliwej do powiązania z Initiative / Tasks / Decisions.
- MUST: nie gubić traceability (skąd powstały notatki i jakie artefakty z nich wynikły).

## Must Not

- MUST NOT: robić silent writes / silent AI execution.
- MUST NOT: udawać pełnego kalendarza, jeśli nie ma integracji.

## Should

- SHOULD: działać jako “capture surface” z możliwością konwersji do artefaktów (np. Tasks/Decisions/Notes).

## Acceptance Criteria

- [ ] Purpose nie przeczy v3 flow (My Work → deliverables) i nie dubluje Notebook.
