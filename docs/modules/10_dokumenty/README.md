# Dokumenty (Document Studio)

## Purpose

Moduł `Dokumenty` opisuje **Document runtime**: generowanie i edycję długich dokumentów (Word/PDF) jako artefaktów v8.1, z Template Registry i QA, bez tworzenia równoległego “file storage”.

W v8.1 doktrynie: Chat jest creation surface, a kanonicznym domem artefaktów jest `Outputs Library` (`/presentations`, zakładka Documents). `Dokumenty` specjalizują *format runtime* dla klasy `Document`.
