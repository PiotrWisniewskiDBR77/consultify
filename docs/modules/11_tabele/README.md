# Tabele (Table Studio / Table Platform)

## Purpose

Moduł `Tabele` opisuje “Table Studio” lane: praca na tabelarycznych danych i szablonach, z audytem/proweniencją, AI operatorem (edytor + QA + source pack), konwersjami do dokumentów/prezentacji oraz intake form (w tym public JWT).

Uwaga: “Tabele Studio” w nawigacji to duplikat tej samej domeny — traktujemy to jako jeden moduł.
