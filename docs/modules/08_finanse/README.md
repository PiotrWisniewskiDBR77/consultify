# Finanse

## Purpose

Moduł `Finanse` jest kanonicznym miejscem **modelowanej prawdy finansowej** (Financial Analysis v3) oraz analiz ekonomicznych (Economics). Jego rolą jest dostarczać profesjonalny runtime analiz finansowych (statements → model → analiza → predykcja → wycena → analiza inwestycyjna) i wspierać decyzje inwestycyjne bez dublowania “metric truth” z Results.

Linkage do `Rezultaty` (KPI/Results) jest **opcjonalne i zdyscyplinowane**: Results trzyma metric truth, Finanse trzyma modeled truth, a linkage wyjaśnia relację zamiast je mieszać.
