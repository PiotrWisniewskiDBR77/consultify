# Prezentacje (Presentation Studio)

## Purpose

Moduł `Prezentacje` opisuje **format runtime** dla klasy `Presentation` / `Deck`: generowanie pięknych, metodologicznie poprawnych i governowanych decków (Gamma-level beauty + Consultify governance).

W doktrynie v8.1: Chat jest creation surface, a kanonicznym domem artefaktów jest `Outputs Library` (`/presentations`, zakładka Presentations). Presentation Studio specjalizuje runtime nad v8.1 substrate i nie tworzy równoległego registry.
