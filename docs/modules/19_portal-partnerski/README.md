# Portal partnerski (Partner Program — partner-facing)

## Purpose

Moduł `Portal partnerski` (`/partner/*`) to partner‑facing powierzchnia programu partnerskiego (P29): onboarding/aktywacja, workspace partnera, directory/resources, client access, commission/earnings oraz payout request (jeśli rola na to pozwala).

Operator truth (hold/approve/execute/reconcile payouts, wyjątki, control tower) należy do `SuperAdmin` (P33) i musi współdzielić **jedną prawdę** lifecycle i ledger.
