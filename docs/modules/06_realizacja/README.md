# Realizacja

## Purpose

Moduł `Realizacja` (Execution) jest operacyjnym runtime’em dostarczania: pokazuje portfolio inicjatyw “w ruchu” i wspiera interwencje PMO/managera na wspólnej prawdzie inicjatywy-zadania-decyzje-zależności.

Kontrakt kanoniczny rozdziela 3 powierzchnie pracy w module:

- `Portfolio` — co jest w realizacji i w jakim stanie
- `Raporty` — predefiniowane pakiety raportowe o stanie dostarczenia
- `Manager` — cockpit interwencji (wykryj → zrozum → zaproponuj → interweniuj → zweryfikuj)
