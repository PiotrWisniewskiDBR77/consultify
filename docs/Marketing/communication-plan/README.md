## Etapy lejka (wspólna definicja)

1. **Awareness** — persona rozpoznaje problem i kategorię rozwiązania.
2. **Consideration** — porównuje podejścia i dostawców.
3. **Decision** — waliduje ryzyko, ROI, bezpieczeństwo; wybiera dostawcę lub model współpracy.
4. **Expansion / Retention** — skalowanie zakresu, kolejne inicjatywy lub pogłębienie partnerstwa.

Szczegóły **proof by stage** i **language guardrails** dla Client GTM: [`../client-message-house.md`](../client-message-house.md).
