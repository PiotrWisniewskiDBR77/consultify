# Asset Gap Map — Consultify

Mapa materiałów potrzebnych do obsługi **całego lejka** i **buying committee**. Status aktualizuj przy powstawaniu assetów.

Legenda statusu:

- **Gotowe (źródło MD)** — kompletna treść w repozytorium (Markdown), gotowa do eksportu lub adaptacji pod konto.
- **Gotowe (materiał zewnętrzny)** — opublikowany PDF/deck lub inny plik poza repo; w mapie można podać link (do czasu publikacji: „—”).
- **Szkic** — wersja robocza wymagająca dopracowania (używaj tylko gdy coś jest niekompletne).
- **Brak** — brak źródła w repo i brak materiału zewnętrznego.
