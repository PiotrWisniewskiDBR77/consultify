# Data room — checklist

**Cel:** Lista folderów i dokumentów typowych dla due diligence. Status **TBD** ustala zespół przed otwarciem roomu.

---

## Struktura folderów (propozycja)

| Folder | Zawartość | Status |
|---|---|---|
| Corporate | Rejestry, umowy wspólników, cap table, uchwały | TBD |
| Financial | P&L, cashflow, prognozy, ostatnie rundy | TBD |
| Legal | Umowy z klientami (anonimizowane), NDA, IP, umowy pracownicze | TBD |
| Product | Roadmap, architektura high level, dokumentacja metodyki | TBD |
| Security | Polityki, subprocessors, DPIA, certyfikacje (jeśli dotyczy), incydenty | TBD |
| People | Org chart, kluczowe umowy, plan hiringu | TBD |
| GTM | Pipeline, forecast, deck, case studies, lista partnerów | TBD |

## Dokumenty „must-have” przed serią A (przykładowa lista)

- [ ] Cap table + SAFE/ASA/convertible docs
- [ ] Ostatnie 12–24 mies. finansów (jeśli dotyczy)
- [ ] Lista klientów / kontraktów (z anonimizacją)
- [ ] Umowy z pracownikami / IP assignment
- [ ] Polityka bezpieczeństwa + lista subprocessors

## Notatki operacyjne

- **Tylko na żądanie:** Szczegółowe umowy z klientami (niepełne kopie), pełne dane osobowe pracowników, materiały objęte NDA zewnętrznym.
- **Wersjonowanie:** Jeden „source of truth” na folder; data w nazwie pliku przy każdej istotnej aktualizacji.
- **Dostęp:** Log kto pobrał / kiedy; watermark na PDF jeśli wymagane przez prawnika.
