# Partner pack — System Integrator (joint pursuit / strategic)

**Cel:** Wejście wyżej w value chain — większy deal, większy wpływ, nie tylko implementacja na końcu.

---

## 1. Joint value proposition (1 akapit)

*SI dowozi integrację, migrację i siłę wdrożeniową u największych klientów; Consultify dodaje **warstwę transformacji i kontroli wykonania** z ROI i security narrative, które są potrzebne na poziomie boardu. Razem wchodzicie wcześniej w cykl — **transformation + delivery**, nie tylko „implementacja na końcu”.*

---

## 2. Joint pursuit one-pager

| Element | Opis |
|---|---|
| Typ dealu | *Digital / cloud / ERP wrap + program transformacji sterowany KPI* |
| Rola SI | *Prime contractor, integracje, zespół lokalny, relacja z CIO* |
| Rola Consultify | *Metodyka, produkt, współtworzenie oferty biznesowej, wsparcie CFO/CEO narrative* |
| Klient docelowy | *Enterprise / upper mid-market, multisite, silny komitet zakupowy* |

---

## 3. Bigger deal case (szablon)

**Sytuacja:** *Klient planował wdrożenie platformy X; brakowało jednego właściciela programu i dowodu biznesowego dla CFO.*  
**Bez Consultify:** *Niższy zakres SI, presja na cenę, ryzyko opóźnień z winy „biznesu”.*  
**Z Consultify:** *Wspólna oferta: platforma + program transformacji z metrykami; wcześniejsze zaangażowanie steeringu.*  
**Wynik:** *Wyższy TCV, lepsza marża usług SI na change, mniejsze ryzyko scope creep bez governance — **liczby wpisujecie po realnym dealu**.*

---

## 4. Proces pursuit (kroki)

1. **Alliance / sales alignment:** wspólna lista kont, ICP, propozycja wartości 1-stronicowa.
2. **Account mapping:** champion biznesowy vs IT; trigger events (nowy CEO, fuzja, program kosztowy).
3. **Joint discovery** z klientem: problem wartości + constraints IT + ekonomia.
4. **Wspólna oferta i budżet:** jeden dokument finansowy dla CFO; załączniki ROI + security.
5. **Delivery model:** podział PMO, integracji, hypercare; wspólna eskalacja.

---

## 5. Ryzyka i eskalacja

- **Konflikt z innym vendorem:** *jasny zakres RACI; „co jest w produkcie SI vs Consultify”.*
- **Scope creep:** *change request tylko przez steering z wpisem do budżetu.*
- **Polityka cenowa:** *jedna tabela rabatów zatwierdzona przez alliance — brak podkupywania w dwóch kanałach.*
