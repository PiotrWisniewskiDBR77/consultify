# Partner pack — Financial Institution (portfolio value / channel)

**Cel:** Lepszy klient = niższe ryzyko portfela; wartość dodana poza samym finansowaniem.

---

## 1. Narracja dla banku / leasingu (1 strona)

**Problem portfela:** *Klienci biznesowi często **nie dowozą transformacji** pomimo inwestycji — rośnie ryzyko operacyjne, cash flow i covenantów; dla banku to nie „IT”, tylko **jakość klienta**.*  
**Rola instytucji:** *Edukacja, intro, program benefitów dla segmentu SME/mid-market — **nie** przejmowanie wdrożenia IT ani odpowiedzialności operatorskiej.*  
**Rola Consultify:** *Dostarcza zrozumiałą ścieżkę „plan + egzekucja + ROI + security” jako usługę do kupienia przez klienta końcowego — z jasnym modelem współpracy z RM.*

---

## 2. Logika „client performance → risk”

| Sygnał | Interpretacja | Działanie |
|---|---|---|
| Spadek przewidywalności przychodów / wzrost kosztów operacyjnych | Możliwy chaos projektowy / brak governance | Program diagnostyczny / voucher na assessment |
| Duże inwestycje w IT bez widocznego efektu | Ryzyko „zatopionego capexu” | Propozycja pilota z KPI (materiały `assets/client/`) |
| Presja regulacyjna / dane | Wyższe wymagania kontroli | Ścieżka security-first + DPA |

---

## 3. Compliance-light FAQ

| Pytanie | Odpowiedź |
|---|---|
| Czy bank wdraża u klienta IT? | *Nie — bank może facylitować intro i benefit program; wdrożenie wykonuje klient i dostawcy pod umowami klienta.* |
| Kto jest umownie klientem Consultify? | *Zazwyczaj firma końcowa; wariant white-label z bankiem wymaga osobnej struktury prawnej — **legal review**.* |
| Dane klienta | *Zgodnie z [`../client/03-security-architecture-faq.md`](../client/03-security-architecture-faq.md); bank nie powinien przekazywać poufnych danych bez podstawy prawnej.* |

---

## 4. Model współpracy (szkic)

| Element | Wartość |
|---|---|
| Kanał dystrybucji | *RM, program dla SME, eventy, współmarking* |
| Komercja | *Fee za intro / rev share / marketing fund — model zależny od regulacji i polityki banku* |
| Pilotaż | *1 segment (np. manufacturing SME) + KPI programu: liczba assessmentów, liczba pilotów, NPS* |

---

## 5. Pierwszy program pilotażowy

*Segment: np. klienci z portfela MŚP powyżej X obrotu; liczba zaproszonych firm: **wpisz**; KPI: **ukończone assessmenty**, **podpisane piloty**, **satysfakcja RM**; okres: 90–120 dni.*
