## Format

Wzorzec narracyjny: zobacz `clients/03-cfo.md`. Wzorzec neutralny (lista pól): zobacz `_template.md`.

Każda persona powinna zawierać dwie warstwy:

### 1. Core Narrative

1. Kim jest w tej narracji
2. Główny cel biznesowy
3. Main pain
4. Hidden emotional pain
5. Jak definiuje sukces
6. Obiekcje
7. Value proposition (1 zdanie)
8. Key messages
9. Kluczowy insight
10. Unikalna wartość Consultify
11. Trigger decyzyjny
12. Jak sprzedawać (praktycznie)
13. Jedno zdanie do użycia na spotkaniu

### 2. Communication and GTM Layer

1. Profil operacyjny
2. KPI i odpowiedzialność
3. Buying committee / ecosystem context
4. Proof pack
5. Źródła informacji i kanały
6. Rola w lejku / motion
7. Content ideas
