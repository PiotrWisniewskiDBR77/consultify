## Core Content (120 sec)

### Point 1: The 5 Principles (40 sec)

"Lean manufacturing is built on five principles:

**Define Value** — from the customer's perspective, not yours.
**Map the Value Stream** — see all steps, identify waste.
**Create Flow** — eliminate batching and bottlenecks.
**Establish Pull** — produce only what's demanded.
**Pursue Perfection** — continuous improvement, never done.

Most companies start with tools — 5S, kanban, TPM. But tools without principles create isolated improvements that don't stick."

### Point 2: The 8 Wastes (40 sec)

"Lean targets eight types of waste — DOWNTIME:

**D**efects, **O**verproduction, **W**aiting, **N**on-utilized talent, **T**ransportation, **I**nventory, **M**otion, **E**xcess processing.

In Consultinity, the GEMBA module helps you capture these wastes in real-time from the shop floor. Operators tag issues. Supervisors review. And the AI identifies patterns you'd otherwise miss."

"Here's the uncomfortable truth: most lean programs fade after the initial push.

Why? Because there's no system to maintain momentum.

Consultinity addresses this through structured initiative tracking. Each lean activity — whether it's a Kaizen event or a process redesign — lives in your roadmap. With owners, deadlines, and measurable outcomes.

You can see which initiatives are progressing, which are stalled, and what results they've delivered. That visibility is what makes lean sustainable."
