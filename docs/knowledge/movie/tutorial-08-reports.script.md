## Core Content (100 sec)

### Report Types (35 sec)

"Click 'Reports' in the left menu.

You'll find pre-built report templates:

**Executive Summary** — One-page overview with key metrics and highlights
**Dimension Deep-Dive** — Detailed analysis of a single area
**Initiative Progress** — Status of all active initiatives
**Trend Analysis** — How scores have changed over time

Each template is designed for a specific audience and purpose."

### Customizing Reports (35 sec)

"Click any template, then 'Customize'.

You can:
- Choose which sections to include or exclude
- Set the date range for data
- Add your company logo and branding
- Write a custom executive summary

Preview your changes in real-time before generating."

### Export Options (30 sec)

"When your report is ready, click 'Generate'.

Export as:
- **PDF** — Professional, ready for printing or email
- **PowerPoint** — Editable slides for presentations
- **Excel** — Raw data for further analysis

Reports are saved in your 'My Reports' library for future reference."

## Summary (10 sec)
