## Opening (10 sec)

"The Roadmap gives you a bird's-eye view of your entire transformation journey. Let me show you how to use it."

## Core Content (120 sec)

### The Timeline View (40 sec)

"Click 'Roadmap' in the left menu.

You'll see a Gantt-style timeline with all your initiatives laid out. 

The horizontal axis is time. Each bar represents an initiative — its position shows when it starts and ends.

Color coding shows status: blue for on track, orange for at risk, red for overdue.

Drag bars to reschedule. Resize them to change duration. It's fully interactive."

### Dependencies (40 sec)

"Some initiatives depend on others. You can link them.

Click an initiative, then 'Add Dependency'. Select the prerequisite initiative.

Now you'll see a connecting arrow. If the prerequisite slips, the system warns you about downstream impact.

This is how you prevent bottlenecks — the kind that kill transformation programs."

### Views and Filters (40 sec)

"The Roadmap offers multiple views:

**Timeline** — The default Gantt view
**Kanban** — Columns for each status stage  
**Calendar** — Monthly view with deadlines

Use filters to focus: show only a specific dimension, a particular owner, or initiatives due this quarter.

You can save filter combinations as 'Custom Views' for quick access."

## Summary (15 sec)

"The Roadmap shows your transformation timeline. Use dependencies to manage flow. Switch views based on what you need to see."

## CTA (10 sec)

"Open the Roadmap now and explore the Timeline view."
