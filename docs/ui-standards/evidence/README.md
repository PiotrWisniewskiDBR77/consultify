# UI/UX Evidence Pack

This directory stores screenshot evidence for DONE cards.

Each card folder includes:
- `STATUS.md` tracking progress (`TODO` / `IN_PROGRESS` / `DONE`)
- screenshot files named per runbook convention

Runbook:
- `docs/ui-standards/UI_UX_DONE_CARDS_EVIDENCE_RUNBOOK.md`
- `docs/ui-standards/evidence/CAPTURE_PLAN_2026-05-04_to_2026-05-08.md`
- `docs/ui-standards/evidence/DAY_YYYY-MM-DD.md`

Automation commands:
- `npm run evidence:sync`
- `npm run evidence:check`
- `npm run evidence:daily -- YYYY-MM-DD`
- `npm run evidence:final`
- `npm run evidence:refresh`
