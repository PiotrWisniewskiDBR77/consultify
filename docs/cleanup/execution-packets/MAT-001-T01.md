# MAT-001-T01 — podłączenie sześciu zakresów AI edit do kanonicznego Document Studio

Status: `READY_SERIAL_INTEGRATOR / PREFLIGHT_REQUIRED`

Baseline przygotowania: `88db01dc0`

Gap: `MAT-001-G01`

Owner danych: Document Studio (`document_studio` schema i editor proposals)

Jedyny writer: istniejące endpointy `/api/document-studio/:artifactId/editor/proposals/*`

## Objective

Zastąpić pustą informację w `TeresaDrawerPanel` rzeczywistym, proposal-first
edytorem AI. Użytkownik wybiera jeden z sześciu zakresów: `local`, `section`,
`global`, `methodology`, `source`, `transformative`; widzi diff i dopiero osobno
zatwierdza albo odrzuca propozycję. `transformative` wymaga dodatkowego,
jawnego potwierdzenia blast radius przed wysłaniem requestu.

## AS-IS

- Kanoniczny host: `DocumentStudioDocumentPanel.tsx`, funkcja
  `TeresaDrawerPanel`; obecnie renderuje wyłącznie instrukcję zaznaczenia tekstu.
- Klient ma komplet sześciu funkcji w `DocumentStudio/api.ts` oraz approve/reject.
- Typy `DocumentEditorScope` i `DocumentEditorProposal` są kompletne w
  `DocumentStudio/types.ts`.
- Diff jest gotowy: `documentDiffModel.ts` i `DocumentSchemaDiffView.tsx`.
- Backend i route istnieją w `server/src/routes/document-studio.routes.ts` oraz
  `server/src/services/documentStudio/documentStudioService.ts`; backendowe
  transformative/refiner tests istnieją i nie są zakresem przebudowy.
- Historyczne `DocumentStudioEditorPanel` i `TransformativeConfirmDialog`
  usunięto w `d1d4f4d0e`; nie są hostem do odtworzenia.

## TO-BE

`TeresaDrawerPanel` montuje jeden współczesny panel propozycji. Zaznaczenie z
TipTap zasila `local`; sekcja zasila `section`; pozostałe zakresy działają na
całym dokumencie zgodnie z istniejącym API. Po utworzeniu propozycji panel
pokazuje `DocumentSchemaDiffView`. Approve podmienia schema przez
`onSchemaUpdated`; reject nie zmienia dokumentu. Każda ścieżka ma loading,
empty, error i retry bez silent fallbacku.

## Kontrakt zachowania

1. Create nie mutuje schema.
2. Approve i reject wymagają `proposalId`; approve zwraca nową schema.
3. `transformative` request nie może wystąpić przed Continue.
4. Cancel, Escape i Continue zamykają dialog i zwracają fokus do triggera.
5. Nie-transformative scopes nigdy nie otwierają blast-radius dialogu.
6. Błąd API pozostawia instrukcję i wybór scope; retry nie tworzy dwóch
   widocznych propozycji.
7. Techniczne `scope`, UUID i audit authority nie są wyświetlane jako surowe enumy.
