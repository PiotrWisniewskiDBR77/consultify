## 🔍 Jak znaleźć sekcje w plikach

### Metoda 1: Wyszukiwanie w edytorze

1. Otwórz plik `public/locales/{lang}/translation.json`
2. Użyj wyszukiwania (Ctrl+F / Cmd+F)
3. Wyszukaj: `"help.sidePanel.modules.{moduleId}"` lub `"{moduleId}": {`
4. Znajdź sekcję z modułem

### Metoda 2: Struktura JSON

Sekcje znajdują się w:

```json
{
  "help": {
    "sidePanel": {
      "modules": {
        "{moduleId}": {
          // Tutaj są tłumaczenia modułu
        }
      }
    }
  }
}
```
