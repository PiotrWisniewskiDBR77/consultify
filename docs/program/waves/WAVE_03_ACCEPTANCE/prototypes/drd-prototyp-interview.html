D · Trzy wymiary zamiast jednej listy

Dlaczego to nie jest komplikacja

Gdyby był jeden select

„Osiągnięty / Częściowo / Nieosiągnięty / Nie wiem / Brak dowodu / Pominięty” — sześć opcji, które mieszają trzy różne pytania. „Nie wiem” wypycha wtedy werdykt, a „brak dowodu” udaje ocenę.

Jak jest w prototypie

Werdykt = co ustaliliśmy o firmie. Wiedza respondenta = czy rozmówca umiał odpowiedzieć. Stan dowodu = ile to jest warte. Trzy pytania, trzy odpowiedzi, trzy kolumny w bazie.

Praktyczny zysk: raport potrafi napisać „poziom 3 częściowo, dowód sprzeczny, rozmówca kompetentny” zamiast jednego nieinformacyjnego „częściowo”. Bez tego rozdziału mikrostruktura komentarza obszaru (punkt „Ocena i wiarygodność”) nie ma z czego powstać.
