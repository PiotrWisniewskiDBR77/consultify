## Zakres E3

- `/projects` przekierowuje do `/my-work` przy fladze OFF i montuje kanoniczny ekran projektów przy ON.
- Użytkownik tworzy projekt, otwiera go w `StandardPreview`, przypisuje role DEC-488 i ustawia alokację per osoba.
- `StandardTable` pokazuje pięć bramek PMBOK-lite: Context → Assessment → Initiatives → Roadmap → Execution → Stabilization.
- Odczyt obcego projektu kończy się 404; zatwierdzenie wymaga roli projektu; zapis receipt i zmiana fazy są atomowe.
- Pakiet nie dubluje H1b, nie dodaje `RESOURCE_RESPONSIBILITY`, `review_requested_at` ani `approved_at`.
