## Bezpieczeństwo i zgodność

- Wszystkie zapisy pozostają pod organizacją projektu; obcy projekt daje 404.
- Nie powstaje menu główne ani drugi rejestr pracy/decyzji/ryzyka.
- Flaga jest domyślnie OFF; OFF zachowuje przekierowanie `/projects → /my-work`.
- E2 nie zapisuje `ie_governance_policies` ani `ie_governance_role_bindings`; pokazuje wyłącznie wejścia do E4.
- **MIGRATION_REQUIRED: NIE.** Wszystkie potrzebne pola istnieją w schemacie `bf580f…`; pula 20262190–99 pozostaje nietknięta.

## RED plan

1. Trasa: OFF zachowuje redirect, ON montuje istniejący `MyProjects`, bez nowego menu.
2. Model operacyjny: role PMBOK-lite, RACI, DEC-480 per osoba, komunikacja i role-derived approval inputs.
3. Dwa różne zespoły muszą dawać różne wejścia do zatwierdzeń.
4. UI: `StandardModuleBar`, `StandardTable` dla projektów i zespołu, `StandardPreview`, formularz projektu, role/opisy, macierz i komunikacja.
