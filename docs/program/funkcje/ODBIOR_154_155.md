## 154 — ciche pęknięcie łańcucha · ocena `A`

**Naprawa dokładnie taka, jak zamówiona — plus jeden dodatek, o który nie prosiłem.**

Zapytanie przestało pytać o nieistniejące kolumny: `i.project_id` → `s.project_id`
przez `LEFT JOIN interview_sessions` po `session_id`, a `i.reviewed_by` →
`NULL AS reviewed_by`. **Dodatek wykonawcy:** złączenie niesie warunek
`AND s.organization_id = i.organization_id` — czyli **pilnuje granicy organizacji**
w miejscu, gdzie instrukcja tego nie wymagała. To jest dobra robota.

**Ciche połykanie usunięte:** `.catch(() => [])` zastąpione przez `catch`, który
**loguje i rzuca dalej**.
