# Status kompletności dokumentacji

## Skala

- `A` — komplet zgodny z nowym standardem i zweryfikowany,
- `B` — mocny kontrakt, wymaga uzupełnienia AS-IS/TO-BE/GAP lub przepływów,
- `C` — materiały istnieją, lecz są rozproszone albo niespójne,
- `D` — brak kontraktu funkcjonalnego,
- `N/A` — funkcja przyszła lub wycofana; dokumentujemy intencję i granice.
