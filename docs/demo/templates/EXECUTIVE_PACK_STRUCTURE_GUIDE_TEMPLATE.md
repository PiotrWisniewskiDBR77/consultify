# Executive Pack Structure Guide (Template)

Version: {{VERSION}}
Date: {{REPORT_DATE}}
Purpose: Define the standard two-document executive package and how it integrates with full and short reports.

## 1) Package Components

This package is built from two separate documents:

1. **Executive Decision Memo**
   - Audience: CEO / steering committee
   - Role: decision-oriented summary
   - Length: 2-4 pages

2. **Financial Assumptions Worksheet**
   - Audience: Finance + Operations + Program office
   - Role: valuation logic and assumption governance
   - Length: 4-8 pages (plus spreadsheet if needed)

## 2) Recommended Production Flow

1. Complete Interview Study Report.
2. Draft Full Consulting Report.
3. Draft Financial Assumptions Worksheet.
4. Build Executive Decision Memo using validated insights + worksheet status.
5. Derive Short Report for leadership circulation.

## 3) Information Hierarchy

### Executive Decision Memo includes
- decision ask,
- top insights,
- top initiatives,
- confidence and risk notes,
- 90-day ask.

### Financial Assumptions Worksheet includes
- baseline register,
- formula logic by initiative,
- scenario structure,
- overlap controls,
- sign-off checklist.

## 4) Consistency Rules

- Memo must never contain financial claims not present in worksheet.
- Short report must not contradict full report.
- Initiative naming must be identical across all documents.
- Confidence labels must be consistent across all pack assets.

## 5) Quality Checklist

- [ ] US English, professional tone, no ambiguous wording.
- [ ] Evidence-backed claims only.
- [ ] No fabricated financial values.
- [ ] Decision ask is explicit and owner-assigned.
- [ ] Document versions and dates are synchronized.

## 6) Final Deliverables Set

Minimum deliverables:
1. Interview Study Report
2. Full Consulting Insights Report
3. Short Report
4. Executive Decision Memo
5. Financial Assumptions Worksheet

This 5-file structure is the standard executive analysis package.
