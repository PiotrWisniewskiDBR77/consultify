## A. Standard Requirements (Must-Have)

### A1. Hard size limit
- Maximum: **10 slides/pages** total.
- No appendix in this version.
- If content does not fit, shorten, do not overflow.

### A2. Objective
- Give leadership a fast decision-ready summary.
- Preserve all critical conclusions from the full report.
- Include the **full initiative list** in compact form.

### A3. Style standard
- One key message per slide.
- Numeric evidence only; no generic wording.
- Decision orientation over narrative detail.

## B. Slide-by-Slide Blueprint (Fixed 10)

1. **Cover + one-line conclusion**
   - Client, date, confidentiality, primary recommendation.

2. **Executive summary**
   - 3 findings, 3 actions, 1 decision ask.

3. **Study snapshot**
   - Scope, sample, completion, confidence, key caveat.

4. **Top insight set (A/B/C)**
   - 3 concise insight statements + impact tags.

5. **Business impact summary**
   - Operational, financial, risk impacts (quantified where possible).

6. **Initiative portfolio map**
   - All initiatives in one impact/feasibility view.

7. **Initiative list (all initiatives)**
   - Compact table: name, owner, horizon, impact, confidence.

8. **Roadmap**
   - 0-90 days, 3-6 months, 6-12 months.

9. **KPI and value snapshot**
   - Baseline, target, value hypothesis.

10. **Decision and next steps**
   - Approval required, owners, immediate actions.

## C. Compact Content Rules

- Insight card max length: **6 lines**.
- Initiative row max length: **1 line per field**.
- Total initiatives listed: **all from full report**, no omission.
- Max text per slide: **90-120 words**.

## E. Quality Gate (Pass/Fail)

1. Exactly 10 slides/pages.
2. All initiatives from full report are present.
3. No contradiction vs full report conclusions.
4. Clear decision ask with owner and timing.
5. Evidence-based wording only.
