# CIIAA Execution Checklist & Guide

**Purpose**: Execute Confidential Information and Invention Assignment Agreements with all team members  
**Deadline**: End of Week 1 (Critical for VC DD)  
**Owner**: Legal + HR + CTO

---

## What is CIIAA?

**CIIAA** = Confidential Information and Invention Assignment Agreement

**Purpose**: Legally assign all IP created by employees/contractors to the company.

**Why Critical for VC DD**: Investors **will not close** without executed CIIAAs. This is a deal-breaker.

---

## Execution Checklist

### Phase 1: Preparation (Day 1)

- [ ] **Legal Review**: Have CIIAA template reviewed by counsel (if not already done)
- [ ] **Identify all contributors**: Create complete list of people who need to sign
  - Current employees
  - Founders
  - Past contractors (if any code contribution)
  - Advisors (if involved in product development)
- [ ] **Prepare signing materials**:
  - [ ] PDF version of CIIAA
  - [ ] DocuSign/HelloSign setup (electronic signature)
  - [ ] Physical copies backup (if needed)
- [ ] **Create tracking spreadsheet** (see template below)

---

### Phase 2: Communication (Day 1-2)

- [ ] **Email to team** (use template below)
  - Explain what CIIAA is
  - Why it's important
  - No negative impact on them
  - Deadline for signing
- [ ] **Schedule 1:1s** (if needed for questions)
- [ ] **FAQ document** ready (see below)

---

### Phase 3: Execution (Day 2-5)

- [ ] **Send CIIAA for signature**:
  - [ ] Founder/CTO
  - [ ] All current engineers
  - [ ] Product/design team
  - [ ] Any contractors who contributed code
- [ ] **Track signatures** in spreadsheet
- [ ] **Follow up** daily with non-signers
- [ ] **Escalate** if anyone resistant (legal counsel)

---

### Phase 4: Storage & Verification (Day 5-7)

- [ ] **Collect all signed CIIAAs**
- [ ] **Store securely**:
  - Physical: Locked file cabinet
  - Digital: Encrypted folder + cloud backup
- [ ] **Create execution certificate** (for DD):
  - Date of execution
  - List of all signatories
  - Confirmation statement
- [ ] **Prepare for DD**: Organize in data room folder

The CIIAA is a standard legal document that:

- Assigns all work product you create for the company to the company
- Protects confidential information
- Is required by all investors before they will invest

Investors will not close a funding round without executed CIIAAs from all contributors. This is standard practice and a deal-breaker if not in place.

## FAQ for Team

### Q: What happens to my side projects?

**A**: The CIIAA typically includes language excluding inventions created entirely on your own time, without company resources, that don't relate to the company's business. Review the specific exclusion language with legal if you have concerns.

### Q: Do I have to sign this?

**A**: Yes, this is a condition of employment for all team members. Investors will not proceed without it.

### Q: What if I've already been working without signing?

**A**: That's okay - we're getting everyone signed now. The CIIAA covers all work product created during your employment, retroactively.

### Q: Can I have a lawyer review it?

**A**: Absolutely. We encourage you to review with your own counsel if you wish. However, please note the deadline for signing.

### Q: What about my GitHub contributions?

**A**: All code contributions to company repositories are covered. The CIIAA formalizes what's already standard practice.

## Troubleshooting

### Issue: Team member refuses to sign

**Solution**:

1. Schedule 1:1 to understand concerns
2. Explain this is standard, not optional
3. Offer legal review if needed
4. Escalate to CEO if necessary
5. Consult employment counsel on next steps

### Issue: Can't reach former contractor

**Solution**:

1. Try all contact methods (email, phone, LinkedIn)
2. Document outreach attempts
3. Consult legal on work-for-hire clause in original contract
4. May need to exclude their contributions or get legal opinion

### Issue: Someone wants changes to CIIAA

**Solution**:

1. Standard CIIAA is non-negotiable
2. Legal can explain standard protections
3. If truly blocking, consult legal counsel
4. Document the issue for DD disclosure
