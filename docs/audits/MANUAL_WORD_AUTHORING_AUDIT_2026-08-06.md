## Acceptance standard for “manual Word complete”

The module should not be declared manually complete until a user can, without Teresa: create a truly blank document; name it; add, remove and reorder sections; author paragraph/headings/lists and persistent inline formatting; create/edit tables, callouts, KPI/risk/roadmap blocks and images with alt text; manage sources/assumptions; find/replace; undo/redo plus restore a persistent version; comment/reply/resolve; run actionable QA; export DOCX/PDF; share and cold-reopen; and complete all primary actions using keyboard only with visible save/error state.

## Local remediation in this pass

1. A manual `Czysto` request now produces one genuinely empty editable paragraph rather than a grounding-warning placeholder.
2. The editor now renders an accessible manual formatting toolbar for paragraph, H1–H3, bullet list and numbered list.
3. Toolbar commands explicitly arm autosave, avoiding the prior programmatic-transaction persistence trap.
4. Targeted tests prove blank-schema behavior and formatting-command autosave. Runtime verification of these patches requires deployment and a second UI pass.
